# Дообучение

- **Где чинить:** модель не умеет — веса, не знает — контекст, знает, но система ненадёжна — обвязка (WCH, вывод
  куратора). Порядок: промпт и контекст → SFT на LoRA/QLoRA → DPO, если есть пары «лучше/хуже» (FT7, куратор).
- **Обучение не заменяет рантайм:** «training-time alignment reduces drift, but runtime enforcement is needed to bound
  it» (ABC, с. 50). Дообученная модель — новая модель: сертификат надёжности не переносится, «shared weights imply
  shared failure modes» (ABC II, с. 12 и 32).
- **Отказы, заданные только промптом, нестабильны;** DPO лучше SFT в 26 из 27 конфигураций, сильнее выигрывают малые
  модели; без примеров отказа модель отвечает на всё (TS, с. 8–9, 26).
- **Для Ally:** «не сейчас» подтверждено; единственная цель для весов — грамматика русского; техника — DPO на LoRA;
  GRPO не брать: награда из наших автопроверок вакуумна — короткий пустой ответ проходит все (BL, с. 28–30).
  Условия возврата — в ADR [On-device model](/engineering/on-device-model.md).

# Что говорит против текущего

- **Пороги П35 слабы:** 0 расхождений судьи с человеком на 20 кейсах по границе Уилсона ещё допускают ≈16%
  расхождений; для 5% нужно ~73 кейса (BL, с. 33, 62; арифметика агента).
- **Журнал нарушений пишет сам фильтр:** сломанный фильтр покажет «ноль нарушений» — нужна независимая пересверка по
  сырому тексту и канарейки (SLM4, с. 42–44).
- **Бейк-офф чинил `rules.py` на том же корпусе** — это значит «корпус больше не находит дефектов», а не «дефектов нет»
  (BL, с. 56); автопроверка пропустила «попроси у дяди помочь найти маму».
