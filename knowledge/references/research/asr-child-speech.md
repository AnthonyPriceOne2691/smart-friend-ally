# Вывод и рекомендация

- **На шаге 3 сравнивать двоих: DictationTranscriber** (на телефоне, с `contextualStrings`) **и GigaAM-v3** (RNNT или
  CTC, int8, через sherpa-onnx). Whisper large-v3-turbo и Vosk zipformer — только планка на Mac.
- **Априори GigaAM-v3 заметно точнее** [замер]: Common Voice — 1,8–2,2% WER против 15,4% у DictationTranscriber;
  дальнее поле Golos — 4,9–6,0% против 27%; суррогат «детского» голоса — 3% против 25%; суррогат с шумом голосов 10 дБ
  — 10% против 47%; живые фразы из 1–2 слов — 91–92% точных против 84%. **На чистых однословных ответах — паритет**
  (92% у обоих); игровая точность после сопоставления с вариантами — ~81% у обоих, ложных принятий 1–2%.
- **Правило решения на шаге 3:** если на её записях GigaAM лучше на ≥10 п.п. (WER или точные однословные), основной
  распознаватель — GigaAM-v3, DictationTranscriber — запасной. Иначе оставить DictationTranscriber (0 МБ, уже в зонде)
  с `contextualStrings`. Цена GigaAM:
  - footprint ~0,7 ГБ — в лимит 6 ГБ входит: E4B 0,5 + Supertonic ~1 + ASR 0,7 ≈ 2,2 ГБ [оценка: E4B — замер на
    телефоне, ASR — `phys_footprint` в ONNX Runtime на Mac, Supertonic — прежний чужой замер на iPhone 16 Pro];
  - +214 МБ к приложению;
  - свой определитель конца речи (и так нужен);
  - промежуточного текста нет (пятилетке не нужен);
  - лицензия MIT [сверено [3]].
- **Независимо от выбора:**
  - держать ≥0,5 с аудио до начала речи (кольцевой буфер): без него у диктовки «пять» → пусто, «Элли» → «Нелли»;
  - имена — подсказкой (`contextualStrings`) и нечётким сопоставлением с вариантами игры; при сомнении — переспросить;
  - имя подруги проверить на распознавателе: «Элли» → «Siri» (2 голоса из 5), «Ниля» → «Нина/Неля», «Аксюша» →
    «Ксюша», «Лоля» → «Оля» [замер: синтетические голоса].
- **Оговорки:** на CV и Golos у GigaAM может быть «домашнее» преимущество (Golos — корпус Сбера); FLEURS (вне домена)
  успели только для диктовки (11,9%); детский голос — только суррогат (сдвиг высоты и формант); диктовка мерена на
  macOS 27, модель iOS может отличаться.

# DictationTranscriber

- **Офлайн.** По документации «uses the same speech-to-text machine learning models as system dictation features do,
  or as SFSpeechRecognizer does when it is configured for on-device operation. This transcriber does not support
  languages or locales that SFSpeechRecognizer only supports via network access» [вендор] [1]. На Mac работает в
  системной службе `localspeechrecognition`, `supportsOnDeviceRecognition` для ru — true, модель ru-RU установлена
  [замер]; на телефоне модель стояла заранее [замер на телефоне]. Сеть — только разовая установка ассета системой; на
  шаге 3 проверить в авиарежиме.
- **SpeechTranscriber без русского** на macOS 27.0.1 [замер] и iOS 27.0.1 [замер на телефоне].
- **`contextualStrings` — основной рычаг:** ≤100 фраз по 1–2 слова [вендор] [2]. Исправляет «Нина → Ниля», «Оля →
  Лоля»; имена 34% → 69%, на CV без изменений (15,4 → 15,4) [замер].
- **Своя языковая модель** (`SFCustomLanguageModelData` → `prepareCustomLanguageModel` → `.customizedLanguage`): для
  ru-RU есть набор из 75 фонем X-SAMPA (ударение `"`, мягкость `'`), подготовка ~0,9 с; вес по умолчанию — почти без
  эффекта; вес 1,0 чинит имена, но CV 15,4 → 20,9%, короткие 84 → 79% [замер]. Включать только на ходы игры; вес
  0,3–0,5 не проверен.
- **Подсказки `.atypicalSpeech` и `.farField`** для ru-RU на macOS 27 не изменили ни одной гипотезы (588 и 288 клипов)
  [замер]. `.frequentFinalization` по документации «less accurate» [вендор]; конфиг зонда дал ту же точность.
- **n-best** (`.alternativeTranscriptions`) — варианты вроде «Нина / Нила / Неля / Миля»; есть `transcriptionConfidence`.
- **Без тишины до речи теряет начало:** «пять», «Лоля» → пусто, «Элли» → «Нелли» (артефакт шага 2). GigaAM устойчив:
  75/80 против 74/80 [замер].
- Модель закрытая — только подсказки. Цифры пишет цифрами — игре нормализовать.

# Протокол шага 3: запись речи дочери и сравнение

> В продукте шаг 3 исполняет `asr-step3` (D7.4) на выгрузке чёрного ящика: живой текст диктовки против GigaAM, вывод —
> только суммы; команда и формат `refs.csv` — [Black box](/ops/black-box.md). Скрипты ниже — план исследования
> 2026-10-18, в репозитории их нет.

**Что нужно на выходе:**

1. 40–50 коротких записей её речи с эталонным текстом, который родитель пишет **до** того, как увидит ответы
   распознавателей.
2. Одна команда на Mac сравнивает кандидатов на этих записях; DictationTranscriber дополнительно гоняется на самом
   телефоне — модель iOS может отличаться от macOS.
3. Решение: какой распознаватель, с какими подсказками, сколько ждать конца речи, какие слова игры переспрашивать.

**Подготовка (родитель, 10 минут):**

- **Чем писать.** Лучше всего — тем же iPhone и тем же путём, что в продукте: режим записи в зонде (микрофон через
  AVAudioEngine, файлы — в контейнер приложения, на Mac — `devicectl device copy from`). Если режима нет — «Диктофон» в
  формате **без потерь** (Настройки → Диктофон → Качество → Без сжатия), **синхронизацию Диктофона с iCloud выключить**
  до записи, телефон в авиарежиме. Перенос на Mac — кабелем или AirDrop, сразу в `local/research/asr/step3/clips/`; с
  телефона после переноса удалить.
- **Где.** Обычная комната, где она будет играть. Телефон лежит на столе экраном вверх, 30–50 см от неё («рядом»); часть
  ответов — с 1–1,5 м («далеко»); часть — при включённом мультике или когда рядом говорит брат («шум»).
- **Как резать.** Один файл — один ответ ребёнка, ~0,5 с тишины до начала и ~1 с после конца. Голос родителя в файл не
  попадает (если попал — пометить в `note`). Имена файлов — коды вида `c01_q07`, без имени.
- **Эталон** — `refs.csv` с колонками `id,ref,kind,distance,noise,note`. В `ref` — слова, которые она **имела в виду**,
  обычной орфографией («рыба», даже если сказала «лыба»); как сказала на самом деле — в `note` («р→л», «шёпотом»,
  «смеётся»). Междометия «ээ», «мм» в `ref` не пишутся. Если родитель сам не разобрал — `ref` пустой, клип в счёт не
  идёт, но остаётся для прослушивания.

**Сессии.** Три коротких сессии по ~10 минут в разные дни, игрой «учим аксолотлика понимать Соню». Остановиться, как
только ей надоело; хвалить за любой ответ; не поправлять произношение во время записи. Подсказки — картинкой или
вопросом, а не «скажи слово X»: иначе она повторяет интонацию взрослого.

**48 подсказок:**

| № | Тип (`kind`) | Что делает родитель | Ожидаемый ответ | Зачем |
|---|---|---|---|---|
| 1–4 | yesno | вопрос с ответом да/нет («Ты любишь мороженое?», «Кошки летают?») | да / нет ×2 | основной ответ игр; короткое слово — главный риск |
| 5–9 | number | показывает пальцы или кубики: «Сколько?» | пять, семь, три, десять, два | счёт — игра «Буль-булька» |
| 10 | number | «Посчитай до десяти» | один … десять | счёт подряд, паузы между числами |
| 11 | number | «Посчитай назад от пяти» | пять … один | то же |
| 12–16 | animal | картинка: «Кто это?» | кошка, собака, аксолотль, лягушка, ёжик | игра «Зверята»; «аксолотль» — редкое слово |
| 17–20 | color | предмет: «Какого цвета?» | красный, синий, жёлтый, зелёный | игра «Какого цвета?» |
| 21–23 | game | «Можно трогать плиту?» / «Ещё поиграем?» | нельзя, можно, ещё | игра «Можно или нельзя?» |
| 24–25 | name | «Как тебя зовут?» (дважды, в разные сессии) | её имя | имя — подсказка распознавателю |
| 26–27 | name | «Как зовут твоего брата?» | имя брата | то же |
| 28–30 | name | «Как зовут аксолотлика?» — по одному кандидату имени подруги | Буля / Лоля / Ниля / Аксюша / Элли | выбрать имя, которое распознаётся |
| 31–36 | phrase | ситуации: «Что ты хочешь?», «Что это?» | «это кошка», «я не знаю», «давай ещё», «хочу мультик», «а что это?», «я сама» | фразы из 2–4 слов |
| 37–40 | why | «Спроси у аксолотлика что-нибудь» | её вопросы «а почему…» | свободная речь, вопросительная интонация |
| 41–42 | story | «Расскажи, что ты делала сегодня» / «Придумай сказку про аксолотлика» | 15–40 с | длинная речь с паузами: проверка конца реплики |
| 43–45 | как у оригинала (`distance=far`) | повтор 5, 12, 17 с 1–1,5 м | как в оригинале | дальнее поле |
| 46–48 | как у оригинала (`noise=tv` / `sibling`) | повтор 1, 6, 21 при мультике или разговоре брата | как в оригинале | шум |

Если сессия идёт хорошо — по 2–3 повтора однословных (разные дни дают разный голос). Итого 40–60 клипов, ~5–8 минут её
речи.

Сравниваются DictationTranscriber без подсказок, с `contextualStrings` и с `.atypicalSpeech`; GigaAM-v3 CTC, RNNT, RNNT с
пунктуацией, RNNT с hotwords; T-one; Vosk zipformer; Whisper large-v3-turbo как внешняя планка. Метрики: WER по словам
«что имела в виду», точное совпадение для однословных, игровая точность (верно / неверно / переспросить), доля пустых
ответов. Статистика — парный бутстрэп разницы WER и точный тест Макнемара по однословным: на 50 клипах различимы только
большие разницы, порядка 10–15 п.п.; меньшие считать «не доказано». DictationTranscriber на телефоне: те же WAV залить в
контейнер зонда и прогнать файловым режимом (как голосовой стенд шага 2, без модели) и сравнить с Mac — решение
принимается по телефону.
