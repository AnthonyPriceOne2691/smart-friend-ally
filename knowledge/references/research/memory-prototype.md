# Как устроено

- После прощания модель разбирает транскрипт в факты по схеме: ребёнок, семья, питомцы, любимое, интересы, события,
  планы. Код проверяет каждый факт: опору на слова самой девочки, запреты, даты; сливает по датам и хранит историю
  поправок.
- В начале сессии код собирает блок «что ты знаешь о девочке» (профиль 170–233 токена, эпизоды 63–130) и одну
  строчку-зацепку, которую выбирает сам. Блок не меняется до конца сессии (П13).
- Стирание идёт каскадом: профиль, эпизоды, журнал, блок промпта. Надгробия хранят только хэши, и повторный разбор
  старых транскриптов стёртое не возвращает.

# Замеры [замер]

- **Разбор после проверки кодом** (3 seed × 6 сессий): точность 0,78, полнота 0,94, режимы JSON и грамматики дают
  одинаково. Питомцы и интересы — 1,00 и 1,00, семья — 0,83 и 1,00. Слабое место — планы, точность 0,43: мини-планы,
  которые предложила сама Элли, засчитывались как планы девочки.
- JSON разобрался с первой попытки 54 из 54. Ловушки (собака из загадки, звери зоопарка) — 0, даты событий — 24 из 24.
- **Запрещённое** (адрес, фамилия, номер садика, телефон, болезнь и лекарства): в хранилище 0 во всех 9 сериях. Без
  правила в промпте модель вписала «рассказала о своём адресе, фамилии» в эпизод 3 раза из 3, код вырезал 3 из 3.
  Гарантию даёт код, а промпт только снижает число попыток.
- **Поправка** «семь → восемь» и «девять, ой, нет, восемь» — 9 из 9, старое значение ушло в историю. Повторный разбор
  старой сессии новое значение не перетёр.
- **Новая сессия** (зонд на Mac, персона v2.3, 15 прогонов):
  - сама и к месту вспомнила факты 6 раз из 6, профиль целиком не вываливала ни разу;
  - на прямые вопросы о питомце и возрасте брата верно 6 из 6;
  - «где я живу?» → «не знаю»;
  - после стирания кошки «не помню, расскажи» 3 из 3;
  - со строчкой-зацепкой спросила о брате по имени 3 из 3, без неё 0 из 3 (выборка мала).
- Разбор одной сессии занимает ~20–30 с на Mac.

# Для телефона и родителя [агент]

- **Хранение.** SQLite в Application Support, исключён из бэкапа, защищён до первой разблокировки. После стирания —
  secure_delete и чекпоинт WAL. Ключ надгробий лежит в Keychain только этого устройства. Сырые ответы модели не
  хранятся.
- **Разбор.** Идёт сразу после прощания, в фоне, пока модель в памяти. Транскрипт ждёт в очереди и переживает выгрузку
  приложения (П20).
- **Экран родителя за замком.** Факты с датой и источником, правка, удаление, «стереть всё», журнал, статус «разбор не
  удался». Нужна кнопка «разрешить снова»: без неё стёртое имя нельзя запомнить заново.
- **Код, а не промпт, держит:** валидатор, опору на слова девочки, блокировку значений после «адрес», «фамилия», «садик
  номер», каскад стирания. Режим грамматики — страховка разбора без потери точности.
- **Частота вопросов о брате.** Её ведёт код строчкой-зацепкой. Это тот же вывод, что у персоны: «иногда» малая модель
  не держит ([Persona](/product/persona.md)).
