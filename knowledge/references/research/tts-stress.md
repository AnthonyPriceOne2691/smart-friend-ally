# Расстановка ударений на телефоне

- **RUAccent** — MIT с 2026-07-17 (раньше CC BY-NC-ND) [сверено: HF `ruaccent/accentuator`, GitHub `Den4ikAI/ruaccent`].
  Модели ONNX: незнакомые слова — 0,8 МБ; омографы — tiny2 10,5 МБ, tiny2.1 41,5 МБ, turbo3.1 359 МБ; «все/всё» —
  14 МБ; словарь — 21 МБ в gz. Омограф решает кросс-энкодер по паре «предложение + вариант» [агент].
- **Silero Stress** — MIT, ~50 МБ, лучший на омографах (0,92 против 0,76 у RUAccent turbo3.1 по замеру Silero), но
  только PyTorch; сторонний ONNX-порт без решателя омографов [агент].
- **Словари:** Зализняк — CC BY-NC (для платной версии не годится); OpenRussian, Викисловарь — CC BY-SA [агент].
- **«ё»:** eyo-kernel — MIT, поиск по словарю, легко переносится на Swift [агент].
- **Скорость:** словарь через mmap — микросекунды, маленькая модель — единицы мс на омограф [агент: оценка].

# Как синтез принимает ударение

- **Supertonic 3:** текст проходит NFKD, «ё» → е + U+0308, U+0301 — обычный токен, общий с латинскими языками;
  синтаксиса ударения нет, сопровождающий пишет об артефактах от акута (issue #132 «Is there a supported syntax for
  specifying word stress?», открыт) [сверено: issue; агент: код]. **Проба 2026-10-18 на Mac это опровергла:** знак
  модель слушается — 55 из 60 верных ударений против 33 из 60 без знака; риск «е → э» — на слух
  ([TTS stress bench](tts-stress-bench.md)).
- **AVSpeechSynthesizer, Milena (macOS 27):** U+0301 и регистр игнорируются (аудио совпадает побайтно), «ё» меняет
  звук, `<phoneme alphabet="ipa">` меняет звук без пауз [замер]. Enhanced на iPhone — не проверено.
- **Голоса с явной разметкой — запасной путь:** Silero v5_cis_base (MIT, «+» перед ударной гласной); Piper с IPA —
  GPL-3.0, только для личной версии [агент].

# Конвейер и проверка

1. Ответ модели («всегда пиши ё» — в промпте) → числа словами → «ё» по словарю → ударения: словарь, модель для
   незнакомых слов, закреплённый словарь имён → разметка под голос (Supertonic — без разметки, заплатки на слух;
   Milena — SSML-IPA для имён и омографов).
2. Проверка голоса — слова во фразах-носителях: омографы (за́мок/замо́к, до́ма/дома́, мука́/му́ка, пла́чу/плачу́,
   бе́лки/белки́), «ё» (всё/все, ёжик, котёнок), прошедшее время подруги о себе (поняла́, взяла́, начала́), числа
   один–двадцать, имена, частые ошибки синтеза (звони́т, краси́вее, то́рты, моро́женое). Автоматически — побайтное
   сравнение (игнорирует ли голос разметку) и распознавание речи (артефакты); остальное — родитель вслепую.
   Порог: имена 100%, омографы 90%, остальное 95%.
