# Engineering

* [On-device model](on-device-model.md) - ADR: модель только на телефоне, за протоколом, выбор замером
* [Safety below the model](safety-below-model.md) - правила безопасности держит механика до синтеза, а не промпт; маршрутизатор до модели — спички и розетка
* [Memory limit](memory-limit.md) - замер: ≈3,3 ГБ без entitlement, ≈6,0 ГБ с increased-memory-limit
* [Model bake-off](model-bakeoff.md) - спайк, шаг 2 на Mac: E4B лучшая по содержанию, E2B — только с маршрутизацией до модели, Bonsai отклонены
* [Model on phone](model-on-phone.md) - спайк, шаг 2 на телефоне: E4B и E2B в llama.cpp — 0,3–0,5 ГБ из 6 ГБ, первый звук p95 1,9 и 1,3 с, детали разговора 7 из 7; русский — у DictationTranscriber
* [Character rendering](character-rendering.md) - ADR: первая версия — 2D-вектор в SwiftUI по прототипу v3 (решение родителя 2026-10-22); Rive «2.5D», RealityKit и клипы — следующий шаг по замеру
* [Persona eval](persona-eval.md) - персона v2: семь кругов на двойнике телефона, итог v2.4 — родитель выбрал живее в 21 паре из 24, безопасность 33 из 45 против 9; частоту и гарантии держит код
* [Turn detector](turn-detector.md) - конец реплики: тип хода по реплике Элли, хвост 1,8 / 1,2 / 2,5 с из реестра слуха, «я всё», «возможно, конец» через 0,3 с, предзапись ≥ 1,5 с, предел 30 с; распознаватель — диктовка или GigaAM по реестру слуха; шаг 3 — `asr-step3`
* [Session](session.md) - сессия кодом: приветствие, «не расслышала» и отдых, её «пока» и мягкий лимит с прощанием фразой кода, крючок маршрутизатора, одна запись следа на ход; в памяти модели — только прозвучавшее; окно брата и имени (третье упоминание брата и имя сверх трети ответов снимаются); в приложении — слушание по состоянию и состояние для экрана
* [App architecture](app-architecture.md) - ADR-002: ядро на Linux, модель отдельным пакетом (llama.cpp b10809, мастер-префикс с файлом состояния), оболочка iOS на трёх рисковых путях; отклонённые варианты
* [Memory](memory.md) - память о ребёнке: факты с опорой на её ход, уверенность считает код, замена по дате, запрещённое не пишется ни на каком пути, блок ≤ 300 токенов (в разговор пока не идёт — решение родителя после M40), консоль памяти, «стереть всё» и «забыть» один факт или сущность с надгробием без значения; серия memory-core → memory-guard → memory-extract → memory-sense → memory-quality → memory-app → memory-recall → memory-forget
* [Voice loop](voice-loop.md) - runbook приложения: сборка, веса на телефон, переустановка одной командой, сессия в консоли, след хода без слов
* [Design demo](design-demo.md) - runbook демо облика на Mac: цель AllyDemo в симуляторе одной командой (`run_demo.sh`), детский режим и сценарий без модели и микрофона, консоль на вымышленных строках, превью Xcode, токены `Look` и `Palette`; граница — демо не в приложении
* [Mac run](mac-run.md) - ADR: Элли на Mac — приложение для iPhone из Xcode (⌘R), файлы через кнопку «Файлы с Mac…», ход строкой без слов в системном журнале; симулятор отклонён — в нём нет диктовки
* [Encyclopedia](encyclopedia.md) - детская энциклопедия «почему»: основы Snowball, SQLite FTS5 в памяти, подсказка только когда поиск уверен, отказ закрытый; с Э2 — база в ресурсах и подсказка в ходе после «pass»; с card-fallback — текст карточки, когда в ответе нет сути
* [Speech text](speech-text.md) - текст для синтеза: ударения по исходному написанию, закреплённое и имена поверх, правила чтения с переносом ударения, U+0301 — только во входе движка; экран и журнал — фраза как есть
* [ONNX Runtime](onnx-runtime.md) - решение: один ORT на приложение — официальный 1.28.0 в Packages/AllyOnnx, слой над C API, страж «один ORT»; sherpa — своим xcframework без ORT
* [Voice engine](voice-engine.md) - движок голоса: Supertonic 3 за протоколом SpeechEngine, фраза за вызов, скорость ≥ 0,85, веса в external data, паритет с Python бит в бит; голос хода SpokenVoice — паузы, стоп, порт звука
* [Accent placer](accent-placer.md) - RUAccent на Swift: токенизаторы с паритетом HF (V3a), логика Python как есть с повтором по записи (V3b), модели — следом
* [Voice FX](voice-fx.md) - обработка после синтеза: своё TD-PSOLA (+9 / +5, «Совсем малышка») и эквалайзер RBJ «light», свой трекер основного тона по методу Boersma без кода Praat; по замерам дребезга равно образцу p9f5
