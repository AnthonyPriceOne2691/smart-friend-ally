# Purpose

Главное обещание продукта — Элли помнит дочь между сессиями: память растёт сама, родитель стирает её в любой момент,
база живёт только на телефоне, настоящие имена — только в ней. Устройство выбрано замером справки
([Memory portrait](/references/research/memory-portrait.md), вариант B): факты с опорой на её ход против фиксированного
профиля — детали 0,75 против 0,13, поправка «Мурка — кошка» 3 из 3 против 0 из 3. Серия подписана родителем 2026-10-23:
`memory-core` (база и блок) → `memory-extract` (что пускают в базу) → `memory-app` (телефон) → `memory-forget`.

# Canonical rules

- **Что хранится:** о ней — имя, возраст, день рождения, любимое по слотам, что любит и умеет; о маме, папе, брате,
  сестре, бабушке, дедушке — имя, возраст, подробности; её питомцы — вид, кличка, окрас, подробности; придуманное — что,
  имя, подробности. Списки закрыты CHECK в базе: новую категорию не добавит ни модель, ни ошибка кода. События «недавно»,
  договорённости, друзья и игрушки — позже, по данным чёрного ящика (решение родителя 2026-10-23).
- **Не хранится никогда:** адрес, телефоны, садик и школа, фамилии, имена чужих взрослых, здоровье, ссоры и наказания,
  деньги, вера, «потерялась» и «чужой дядя», секреты, пароли. Держит `memory-extract` — проверка значения и триггер базы
  на любом пути записи; до неё у базы нет писателя.
- **Опора и уверенность:** у факта — сессия и номер хода её реплики (тот же номер, что в следе и в чёрном ящике); слова
  девочки не копируются. Уверенность считает код по виду опоры: сказала сама — 0,9, опору нашёл код — 0,8, согласилась
  на предложение Элли — 0,6; каждая следующая сессия — лучшая опора плюс 0,05, не выше 1,0. Поля уверенности у входа нет.
- **Замена и подтверждение:** однозначное (имя, возраст, день рождения, вид, окрас, любимое в слоте) заменяется значением
  из сессии не старше активного, прежнее уходит в историю; более старая сессия новое не перетирает. Многозначное
  копится. Сессия считается для факта один раз (`seen`): повтор записи ничего не меняет, и порядок записи сессий не
  меняет ни счёта, ни уверенности, ни написания — остаётся написание самой ранней сессии.
- **Узнавание:** она — одна; близкий — по отношению и имени без регистра и «ё», безымянный — единственный своего
  отношения; питомец и придуманное — по кличке, без неё — единственный своего вида.
- **Блок для промпта** (П11, П13): шапка из `memory.json`, строки — она, любимое, любит, умеет, брат и сестра, питомцы,
  остальная семья, придуманное; внутри строки — по первому появлению; потолки строк 4 / 3 / 3 / 3 / 2 / 1; бюджет 300
  токенов по счётчику вызывающего (на Linux — ⌈скаляров / 2,7⌉, с запасом к токенизатору 2,71–2,80); сверх бюджета
  уходит сначала наименее важное, ядро — её имя и возраст, брат и сестра, питомцы — не уходит никогда. Пустая память —
  пустой блок: системный ход остаётся персоной байт в байт.
- **«Стереть всё»:** соединение закрывается, файлы базы и спутников удаляются, база создаётся заново с эпохой стирания;
  сессия, начатая раньше эпохи, не записывается. Спутники базы (`-wal`, `-shm`, `-journal`) — данные ребёнка: их не
  пускает в git гейт `child-data` ([Child data](/ops/child-data.md)).
- **Общий SQLite:** системный модуль `CSQLite` и тонкая обёртка — пакет `Packages/AllySQLite` (решение ведущего
  2026-10-23); энциклопедия стоит на нём же, своего модуля SQLite никто не заводит.

# Что ещё не подключено (L50)

Пока нет `memory-extract` и `memory-app`, у базы и блока нет вызывающего: Элли в приложении ещё ничего не помнит.
Разбор E4B после прощания, отбор реплик (только `pass` без `forget`, только детские сессии при родителе), очередь,
блок в префиксе персоны, файлы на телефоне (`Application Support/Memory`, вне бэкапа, `NSFileProtectionComplete`) и
кнопка «Стереть память» в консоли — следующие поставки серии; забыть один факт и счётчики брата и имени — `memory-forget`.
