# Status

Принято: спека и план D1 подписаны родителем 2026-10-20; D1.1 `voice-core` слита 2026-10-22, D1.2 `app-voice-loop`
реализует оболочку. Решения родителя E1–E5 от 2026-10-19.

# Context

- Рабочий цикл зонда без тестов и реестра — 799 строк; предохранитель поставки — 800 строк и 25 файлов, E1 его не
  поднимает, а даёт три рисковых пути (звук, распознавание, модель) только для D1.
- Правила безопасности держит код, а не промпт (L25): каждый ответ модели обязан пройти `TurnContract` до голоса.
- Модель занимает память и GPU вместе со всем остальным в лимите ≈ 6 ГБ ([Memory limit](/engineering/memory-limit.md)).

# Decision

- **Слои.** `Packages/AllyDiscipline` — ремонт текста, контракт, маршрутизатор (Linux CI). `Packages/AllyCore` — ход
  через контракт, конец реплики, журнал без слов, реестр и проверка весов, срок подписи (Linux CI, покрытие ≥ 70%).
  `Packages/AllyLlama` — модель за протоколом `LanguageModel` (Mac и телефон; паритет со стендом A23). `App/` — оболочка
  iOS: звук, распознавание, голос, консоль; политику платформы трогают только `App/Sources/Audio/`, `App/Sources/Speech/`
  и пакет модели.
- **Рантайм** — llama.cpp b10809, релизный xcframework по url и checksum (бинаря в git нет).
- **Контекст** — n_ctx 8192, четыре последовательности с общим KV и полным окном SWA (KV 448 МиБ); персона —
  мастер-последовательность, разговор — её копия; префикс — файлом состояния в `Caches/`. С `memory-recall` в
  системном ходе идёт и блок памяти (новая форма, включён решением родителя 2026-10-29): новый префикс собирается в стороне
  (последовательность 3) и копируется в мастер целым, файл — с полной защитой и уходит со стиранием памяти
  ([Child data](/ops/child-data.md)).
- **Проект** — XcodeGen из `App/project.yml`; `.xcodeproj` и файл прав генерируются; команда разработчика — в
  игнорируемом `App/Local.xcconfig`, UDID — аргумент команд.
- **Реестр** `App/Resources/model.json` — веса и размер, рантайм, сэмплинг, персона, голос, тайм-аут первой фразы (П10);
  пины sha256 — в `delivery/model_surface.txt`, checksum рантайма — в `Package.swift`. Хвосты по типу хода, предел реплики
  и тайм-аут слушания — реестр слуха `App/Resources/hearing.json` (D7).

# Rejected alternatives

- Один D1 на ≈ 1 300 строк с подписанным предохранителем — ревью и разбор отказа на телефоне дороже второго PR.
- Ядро в D2 — без `TurnRunner` цикл звучал бы мимо контракта.
- Нарезка первой фразы по сырому тексту — контракт чинит ответ до нарезки: «Слон весит 2.» звучало бы «Слон весит два.».
- LiteRT-LM — GPU-делегат закрыт, Swift API — превью ([Model on phone](/engineering/model-on-phone.md)).
- SpeechTranscriber и `SFSpeechRecognizer` — у первого нет ru-RU (L23), второй может распознавать на сервере.
- Голос «лучшего качества» по языку и веса в `Documents` — мягкий выбор молча подменяет голос (П23), `Documents` уезжает
  в бэкап iCloud.
- `.xcodeproj` в git — сгенерированный файл съел бы предохранитель и конфликтовал бы на каждом мерже.
- Хэши в `model.json` — detect-secrets принимает 64-значный hex в кавычках за секрет.
- macOS-раннер на каждый PR — минута ×10 (CQG §8.7); ручная джоба `ios.yml` раз на поставку (E3).
- Малое окно SWA (KV 168 МиБ) — копия мастер-префикса падает («no slot»), срез хвоста для перебивания молча портит KV.
- Сборка префикса на каждом запуске — ≈ 3,8 с prefill на телефоне против чтения файла (0,015–0,018 с на Mac).

# Consequences

- Linux CI судит ядро и форму кода; модель — паритет на Mac (A23: 37 из 37 токенов, ответы 35–37 из 37), оболочку —
  оракул артефакта и прогоны на телефоне ([Voice loop](/engineering/voice-loop.md)).
- Каждая следующая поставка — один рисковый путь (E1 только для D1).
