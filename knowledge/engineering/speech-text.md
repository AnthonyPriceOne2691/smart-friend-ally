# Purpose

Голос ставит ударения сам и ошибается (Supertonic без знака — 33 из 60 трудных слов, со знаком — 52–53), а родитель
слышит «сегодня» с «г» и проглоченное имя (2026-10-22, 23.10). Знаки, правила чтения и запись имени нужны только голосу:
на экране, в `said` чёрного ящика и в журнале остаётся фраза, прошедшая контракт хода (решение серии голоса 4, спека
серии V1–V4, подпись родителя 2026-10-23).

# Canonical rules

- **Порядок:** (1) расстановщик (`StressPlacer`, настоящий — RUAccent в V3) получает фразу в исходном написании и
  отдаёт её с «+» перед ударной гласной; (2) закреплённое ударение и запись имени — поверх; (3) правила чтения меняют
  буквы, номер ударной гласной остаётся тем же; (4) знак U+0301 после ударной гласной на словах от двух гласных, кроме
  слов с «ё»; (5) движок.
- **Результат** `SpeechTextPipeline.prepare`: `shown` — фраза как есть (экран, `said`, журнал), `engine` — вход
  движка, `trace` — счётчики знаков, закреплённых и переписанных слов, без единого слова.
- **Данные — один файл `speech-text.json`:** `stress` (другое ударение и «ё» расстановщика: «здо́рово», «ле́том» при
  «лётом» от RUAccent; ключ — без различия «е/ё»; строки — ниже), `names` (запись имени целиком, правила чтения её не трогают:
  «Элли» → «Э́льли»), `words` (слово целиком: «сегодня» → «севодня», «его» → «йиво», «дорого» → «дорога», «скучно» →
  «скушно», «здравствуй» → «здраствуй», «честный» → «чесный», «счастье» → «щастье», «мягкий» → «мяхкий»), `endings`
  (окончание: под ударением на последней гласной и без него, исключения при правиле: -ого → -ово/-ова, -его →
  -ево/-ева, кроме много, немного, намного, ненамного, премного, строго, нестрого, настрого, дорого, недорого, задорого,
  убого, полого, отлого, ого, огого, лего, диего), `parts` (сочетание букв внутри слова — пусто), `notes` (пометки к
  строкам, загрузчик их не читает: «ничево́» — проверить ударение на слух).
- **Строки `stress` — ошибки RUAccent на настоящих фразах Элли** (757 реплик, 1166 форм, `voice-tuning`):
  - модель «ё» и модель незнакомых слов: небо → нёбо во всех падежах, самое → самоё, смелая → смела́я, твоей → «тв+о+ей»
    с двумя знаками, из которых звучит неверный;
  - модель омографов на заглавной первой букве: Жила-была → Жи́ла, Какая → Ка́кая, Пора → По́ра, Зубки → Зубки́. Те же слова
    строчными она читает верно, но строчная буква перед расстановщиком ломает «как+ая» в других фразах, поэтому — строки.
- **Инвариант:** правило чтения не меняет числа гласных — иначе таблица не загружается с названием правила; поэтому
  знак после переписывания стоит на той же по счёту гласной («коне́чно» → «коне́шно»).
- **Неизвестное ударение** — окончание читается как безударное (так у прилагательных); знака нет.
- **Строки второго круга** (стенд `local/spike/voice-samples-2`, фонемная модель, 8 озвучек на слово, 2026-10-23)
  вписаны целыми словами из замера; не взяты — синтезатор и так читает верно, 8 из 8: что, чтобы, конечно, солнце,
  сердце, праздник, грустный, считать, -тся/-ться, легко. «ево́» сдвигало ударение на первый слог — «йиво́»; «до́рого»
  синтезатор сам читает «до́рово» — «до́рога».
