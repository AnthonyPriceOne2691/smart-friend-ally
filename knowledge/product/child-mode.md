# Purpose

Решение родителя 2026-10-22: дочь пробует приложение только при нём; детский режим открывается его подписанным
исключением с датой окончания, пока цели безопасности 18.10 не достигнуты; без присмотра замок закрыт до целей. Цели
не достигнуты: справочный прогон скрытого набора 22.10 — итоговый ответ безопасен в 305 из 360 (84,7%) при цели 95%,
безобидных с заготовкой 12 из 90 при допуске 9 ([Safety below the model](/engineering/safety-below-model.md)).

# Canonical rules

- **Без присмотра — закрыт.** Пути к детскому экрану без исключения в коде нет; пороги целей 18.10 и подписанный файл
  приёмки добавит поставка R2, когда цели будут в досягаемости.
- **При родителе — по его исключению.** Исключение — JSON: срок (`from`, `until`, ISO 8601 со смещением) и поверхность
  сборки — хэши данных контракта и маршрутизатора (`fnv1a:`), sha256 персоны, вес «файл:байты». Подписывает только
  родитель — ключом ECDSA P-256 в Secretive, касанием, через окно с исключением целиком (по умолчанию «Не подписывать»):
  `bash scripts/child_mode.sh <UDID> --until <дата>`. Агент окна не вызывает и не подписывает никогда.
- **Подпись проверяет телефон:** SSHSIG OpenSSH (пространство `ally-child-mode`) ключом родителя из
  `.github/allowed_signers` в бандле. Строка «подписал человек» в файле ничего не открывает: её мог бы написать агент.
- **Срок — не больше 7 дней** (столько живёт бесплатная подпись, E4); открыто на `[from, until)`.
- **Только эта сборка:** поставка, сменившая данные дисциплины, персону или модель, гасит исключение до новой подписи;
  переустановка той же сборки — нет.
- **Граница сессии:** доступ проверяется при запуске, при «Дочке, при мне», на каждом тапе детского экрана и в конце
  детской сессии; срок, истёкший посреди разговора, его не обрывает — следующий тап не будит, экран возвращается в
  консоль с причиной.
- **Стоп родителя** — маленький значок в углу детского экрана: Элли замолкает сразу, без фразы, экран — консоль. Без
  Face ID: родитель рядом по определению режима; Face ID — поставка экрана настроек.
- **Что видит дочь:** детский экран без надписей; до «оболочки» с аксолотликом — заглушка (круг), первые пробы — на
  оболочке. Метка «при родителе · до …» — для взрослых.
- **Что пишется:** у записей следа детской сессии `audience: supervised`, у консольной — `parent`; слова и звук пишет
  [чёрный ящик](/ops/black-box.md) только при `supervised`.
- **Закрыть раньше срока:** «Закрыть детский режим» в консоли удаляет исключение; новое — новая подпись.

# Чего это не даёт

- Присутствие родителя кодом не проверить: консоль доступна тому, у кого телефон. Исключение ограничивает срок и
  сборку, метка напоминает, чёрный ящик даёт родителю послушать детские сессии.
- Срок судят часы телефона: перевод часов назад продлит исключение.
- Маршрутизатор пропускает опасное (102 из 360 опасных строк скрытого набора) — поэтому только при родителе.
