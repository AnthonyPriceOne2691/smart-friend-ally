# Purpose

Решение пользователя 2026-10-02: транскрипты пишутся в «чёрный ящик», чтобы потом
улучшать подругу и смотреть за прогрессом, выгружая данные на Mac; писать **текст
и звук всегда**. Ребёнок не скажет, что подруга ошиблась, — единственный
наблюдатель качества здесь родитель, а чёрный ящик и есть его оракул (П32).

# Что пишется

Единица — ход, группа — сессия ([Session limit](/product/session-limit.md)).

| Поле | Зачем |
|---|---|
| звук ребёнка — поток **после эхоподавления**, тот, что слышит распознаватель | проверка и настройка распознавания на её настоящей речи — главный риск проекта (KNOWLEDGE.md §6) |
| текст распознавания ребёнка | что поняла подруга |
| текст ответа подруги, до и после контракта | что модель хотела сказать и что прозвучало |
| сработавшие правила безопасности — до восстановления | дрейф промпта виден только так (П5) |
| время по этапам: конец фразы → распознавание → первый токен → первый звук | гейт задержки p95 ≤ 3 с на реальных разговорах |
| версии: iOS, рантайм, хэш файла модели, идентификатор и параметры голоса | разговор воспроизводим, поведение без диффа объяснимо (П26) |
| мета-ходы («повтори», «не хочу») | фильтрует читатель, а не писатель (П21) |

Звук подруги не пишется: он восстанавливается из текста, идентификатора и
параметров голоса.

# Где хранится

- **На телефоне** — в песочнице приложения, защита файлов `NSFileProtectionComplete`,
  `isExcludedFromBackup = true`: в iCloud-бэкап журнал не попадает.
- **Объём:** голос ребёнка сжатым AAC 16 кГц моно ~24 кбит/с — около 0,2 МБ на минуту
  речи, сессия меньше 2 МБ `[оценка]`.
- Пишется сразу, ход за ходом: приложение могут закрыть без предупреждения (П20).

# Выгрузка на Mac

- **Только без облака:** по кабелю — `xcrun devicectl device copy from` (контейнер
  приложения) либо Finder (общий доступ к файлам приложения); по воздуху — AirDrop
  (прямое соединение устройств) `[оценка: выбрать на первой поставке с записью]`.
- **Куда:** `local/blackbox/<дата>/` в репозитории — каталог игнорируется git, и гейт
  `check_child_data.py` не пускает аудио и тексты в коммит даже через `add -f`.
- **Сторож облака на Mac:** скрипт выгрузки отказывается писать в каталог,
  синхронизируемый с iCloud (`kMDItemIsUbiquitous`, путь под `Mobile Documents`). На
  2026-10-02 синхронизация «Документов» на этом Mac выключена — проверено, но
  включить её можно в любой момент, поэтому держит механика.
- После выгрузки родитель может стереть журнал на телефоне.

# Стирание

- **Отдельные кнопки:** «стереть память подруги» (она знакомится заново) и
  «стереть чёрный ящик»; «стереть всё» делает оба. Память влияет на разговор,
  журнал — материал родителя: одно не должно молча уничтожать другое.
- Обе под родительским замком; после стирания экран показывает, что удалено (П22).

# Чем это станет на Mac

- **Качество:** родитель читает разговоры; плохие ходы становятся кейсами набора
  для проверки поведения модели (П35).
- **Распознавание:** записи её голоса — эталон для сравнения распознавателей
  и, если понадобится, для дообучения.
- **Прогресс:** словарь, счёт, любимые темы — по сессиям во времени.

# Остаток, названный честно

Микрофон пишет всё, что звучит рядом во время сессии, — и голоса других людей.
