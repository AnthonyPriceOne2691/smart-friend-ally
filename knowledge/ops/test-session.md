# Purpose

Решение родителя 2026-10-23: все проверки на телефоне идут в одну общую сессию теста, а поставки сливаются по зелёным
Mac и GitHub (ответ «Да, всё в общую сессию (Рекомендую)»; для слуха — ответ 8 серии «слух»: проверки после D7.1 и
после D7.3). Отложенные проверки лежат в waiver'ах и eval-smoke двенадцати поставок и в списках ожиданий серий. Здесь —
всё в одном месте: что подготовить, что подписать, что проверить по порядку и где записать итог. Новых проверок здесь
нет: каждая — пример подписанной спеки со ссылкой на её архив.

# Правила сессии

- **Ставит и подписывает только родитель** (manual-deploy, канон §3.4a): установка на телефон, касание ключа Secretive,
  подпись детского режима. Ведущий или агент запускает команды на Mac по его слову; окно Secretive без просьбы родителя
  не вызывается.
- **Снимков экрана нет** (L46): экран — консоль «Для взрослых», точка микрофона, детский экран — подтверждает родитель
  на глаз.
- **Данные — только в `local/`:** след хода, журнал консоли, выгрузка чёрного ящика. В git — только итоги в `observed.md`
  (числа и вердикты, без слов и записей). Если в детском режиме говорит дочь, её записи идут в чёрный ящик и после
  выгрузки — в `local/blackbox/` ([Child data](/ops/child-data.md)).
- **Телефон не блокировать** во время прогонов: блокировка останавливает работу GPU, а ход, кончившийся позже 10 с после
  блокировки, чёрный ящик не пишет.
- **Пометка «после <поставка>»:** шаг выполняется, только если поставка к сессии в main. Нет — шаг пропускается и
  остаётся в долге её наблюдения.

# 1. Подготовка на Mac

1. **Телефон и UDID:** телефон на кабеле или в одной сети с Mac, разблокирован; `xcrun devicectl list devices`.
2. **Ключ родителя в сборке** (после D3.2 — она кладёт строку в `.github/allowed_signers`, формат — в самом файле:
   `namespaces="ally-child-mode,ally-release"`). Без строки детский режим закрыт с причиной «в сборке нет ключа
   родителя» — блок 3.5 пропускается. Ключ попадает в бандл при сборке, поэтому строка должна быть в main до шага 3.
3. **Переустановка одной командой — она же проверка W11** (`delivery/archive/2026-10-22-app-session/`):

   ```bash
   bash scripts/reinstall_app.sh <UDID>
   xcrun devicectl device info files --device <UDID> --domain-type systemCrashLogs   # список падений «до»
   ```

   Смотреть (W11): сборка с подписью, оракул артефакта зелёный; список `Library/Application Support/Models` до и после
   одинаков; приложение стоит поверх и запущено; строка скрипта «подпись до …, N дн.» совпадает с консолью «подпись:
   осталось N дн.» ± 1. Первый запуск новой подписи — доверие сертификату на телефоне (L15).
4. **Модели и файлы на телефон** — только то, чего нет в контейнере (скрипт переустановки печатает команду
   копирования, если весов нет). Каталог на телефоне — `Library/Application Support/Models`:

# 2. Шаг владельца

1. **Ключ Secretive** — один раз: ключ ECDSA P-256 в Secretive на Mac родителя, его открытая строка — в
   `.github/allowed_signers` (поставкой, см. 1.2). Ключ требует касания; агент окна не вызывает и не подписывает никогда.
2. **Подпись детского режима — она же проверка G11** (`delivery/archive/2026-10-23-child-lock/`):

   ```bash
   bash scripts/child_mode.sh <UDID> --until <дата не дальше 7 дней, ISO 8601 со смещением> --dry   # текст окна
   bash scripts/child_mode.sh <UDID> --until <та же дата>                                             # окно и касание
   ```

   Смотреть (G11): окно показывает исключение целиком, кнопка по умолчанию «Не подписывать» — Enter ничего не подписывает
   и не копирует; «Подписать» и касание — `ssh-keygen -Y verify` зелёный, оба файла в контейнере, консоль «при родителе:
   до <дата>» (поверхность скрипта совпала с приложением, иначе отказ G5); `--until` дальше 7 дней — отказ до окна.
   Подпись — на собранную в 1.3 сборку: после новой переустановки исключение подписывается заново.

# 3. Проверки на телефоне — по порядку

Одна установка на всё, кроме двух последних шагов блока 3.8 (GigaAM и база X8 — каждая со своей сборкой, в самом
конце). След хода снимается после каждого блока; каждое число берётся из строк своего блока. Итог каждой проверки — строкой
в `delivery/archive/<поставка>/observed.md` (раздел 4). Запуск с консолью:


## 3.2 Разговор в консоли

- **W9** (`2026-10-22-app-session`) — «Дай мне спички» и «Я живу на улице Морковной, дом семь». Смотреть: дословно
  звучат подписанные фразы `matches` и `pii`; в следе — `script:matches` и `script:pii` с `forget: true`; падения нет.
- **U6** (`2026-10-23-turn-detector`) — «Разбудить»; на «Что у тебя нового?» — фраза с паузой ≈ 1,2 с посередине; на
  вопрос с ответом да или нет — «Да»; длинная фраза — и «Я всё» посреди неё. Смотреть: фраза с паузой — одна реплика,
  без «не расслышала»; на «Да» Элли отвечает; «Я всё» кончает ход не позже 0,1 с после тапа, кнопка активна только во
  время слушания. След: `turn_kind` каждого хода — тип последней фразы Элли по U1; `stages.tail` — хвост типа ± 0,12 с;
  у хода с «Я всё» — `turn_done: 1`.
- **W10** (`2026-10-22-app-session`) — «Стоп», пока Элли говорит; «Стоп», пока слушает; сразу после — «Разбудить».
  Смотреть: на первый — тишина сразу, запись `cancelled` с причиной `parent`, «Элли: спит»; на второй — «Элли: спит»
  сразу, запись `session:stop`, точка микрофона гаснет не позже конца слушания (≤ 8 с); приветствие новой сессии — после
  того, как закрылся микрофон.
- **Z26** (после V4b `voice-app`; спека серии голоса и правки V4b) — на слух: имя звучит «Э́льли», «сегодня» —
  «сево́дня»; при +9 / +5 нет металла и «бурундука»; имя не проглатывается после обработки; замер — звук телефона после
  обработки равен звуку Mac на той же фразе и зерне, SNR ≥ 40 дБ.
- **M37** (после `memory-app`; спека серии памяти `2026-10-23-memory-core`) — сессия с вымышленными «у меня кошка Мурка,
  она рыжая» и «брату Тёме восемь» → разбор → новая сессия: «Как зовут мою кошку?» — «Мурка», 3 из 3; после «Стереть

## 3.3 Двадцать ходов — задержка и цена одним прогоном

Двадцать ходов родителя на открытые и закрытые вопросы Элли, на динамике. Из тех же строк следа и журнала:

- **A10** (`2026-10-22-app-voice-loop`) — конец речи → первый звук p95 ≤ 2,5 с; p50 и разбивка — хвост, распознавание,
  первая фраза, голос — числами (замер 2026-10-22 до правки кадров — 2,65 с).
- **U14** (`2026-10-23-turn-speculation`) — p95 `speech_end_to_sound` ≤ 2,5 с; p50 и p95 по типам хода, доля
  `spec_reused`, `spec_cancels` на ход.
- **U15** (`2026-10-23-turn-speculation`) — текст на «возможно, конец» равен тексту на хвосте (по буквам) не меньше чем в
  18 из 20; меньше — спекуляция с диктовкой названа слабой, решение — ведущему.
- **U20** (`2026-10-23-silero-vad`) — время окна Silero p95 ≤ 2 мс (журнал, категория `hearing`: «silero: windows N p95
  X ms» на каждое слушание); прирост footprint от Silero ≤ 40 МБ — против прогона с энергией из блока 3.7.
- **Z22** (после V4b) — p95 «конец её речи → первый звук» ≤ 2,5 с с обработкой голоса; прирост отпечатка от голоса
  ≤ 0,4 ГБ.
- **X8** (после D5 `kv-spoken`) — первая фраза следующего хода не позже, чем на main без D5, более чем на 0,1 с p95;
  отпечаток не растёт. База — блок 3.8.
- **X12** (после D6.1) — p95 ≤ 2,5 с, как Z22; AGC замерен включённым и выключенным, выбор записан.
- **B21** (после D3.3; спека серии чёрного ящика `2026-10-23-black-box`) — p95 первого звука не больше, чем у D1.2 (A10),
  плюс 0,05 с.
- **P20** (после Э2 энциклопедии; спека `encyclopedia-core`) — отдельные ходы с подсказкой: «почему небо голубое» —
  ответ с сутью карточки, «где мой мишка» — без подсказки; поиск p95 ≤ 10 мс; первый звук на ходах с подсказкой p95 — не
  хуже + 0,15 с.

## 3.5 Детский режим при родителе

После шага 2.2. Порядок: G10 → V29 → чёрный ящик → G8 (короткое исключение — последним, оно заменяет длинное).

- **G10** (`2026-10-23-child-lock`) — «Дочке, при мне» открывает детский экран с меткой «при родителе · до …»; тап по
  кругу — приветствие; значок стопа — Элли замолкает сразу, без фразы, запись с причиной `parent`, экран — консоль;
  «Закрыть детский режим» удаляет исключение — консоль «нет исключения родителя», «Дочке, при мне» недоступна. Перед
  блоком чёрного ящика — подписать исключение заново (2.2).
- **V29** (после Ш3) — «Дочке, при мне» — Элли в пузыре с венком, метка и стоп, строки состояния и полоски «домой» нет;
  тап по спящей — вздрагивает, просыпается и машет; тап, пока слушает, — «я всё»; тап, пока говорит, — ничего; стоп —
  тишина и консоль; «слушает» идёт 120 кадров в секунду (Instruments); замер бюджета по таблице Ш1 (память, рывки,
  скорость модели, нагрев).
- **B13–B19** (после D3.2 `app-black-box`) — хранилище: у `Library/Application Support/BlackBox` пометка «не в бэкап»
  читается обратно, у файлов класс `NSFileProtectionComplete`, консоль «● запись» (B13); формат распознавателя на
  старте — строкой консоли, число отсчётов в WAV хода равно отданным распознавателю (B14); режим при каждом запуске
  выключен, сессии `audience: parent` файлов ящика не оставляют (B18); записей ящика столько же, сколько строк следа, WAV у
  каждой услышанной реплики (B19). B15–B17 — в разделе 4.
- **B22** (после D3.3) — сессия 10 минут в режиме при родителе: ящик ≤ 10 МБ.
- **G8** (`2026-10-23-child-lock`) — исключение до «сейчас + 3 мин» (шаг 2.2 с этой датой); детская сессия начата до

  ≤ 450 МБ; расшифровка реплики 3 с p95 ≤ 0,5 с (этап `recognize`); 20 ходов в авиарежиме, ничего не скачивается.
  После — обратно на сборку main.
- **База X8** (после D5) — первая фраза p95 на сборке без D5. Если D5 к сессии в main, откуда взять базу — решает
  ведущий; вариант — установка коммита перед её сквошем в конце сессии, 20 ходов как в 3.3.

# 4. Чем закончить

1. **След и падения:** последний `copy from` следа; `xcrun devicectl device info files --device <UDID> --domain-type
   systemCrashLogs` — новых отчётов о падении Ally 0 (сверка со списком «до» из 1.3).
2. **Чёрный ящик** (после D3.2) — выгрузка и стирание:

   ```bash
   python3 scripts/blackbox.py pull --device <UDID>    # B15: в local/blackbox/<дата>/, сверка байт и FNV-1a
   python3 scripts/blackbox.py erase --device <UDID>   # B16: сначала выгрузка, стираются только сверенные сессии
   ```

   Смотреть: B15 — итог «выгружено: N сессий, M МБ, сверено N из N», телефон заперт — «разблокируй телефон»; B16 —
   несверенная сессия остаётся и названа, итог «стёрто: N сессий, M МБ»; B17 — кнопка консоли «Стереть чёрный ящик» с
   подтверждением, во время сессии недоступна. Стирание необратимо: поверхность подписана пальцем родителя при сдаче
   D3.2.
3. **Детский режим:** «Закрыть детский режим» в консоли — исключение удалено.
4. **Итоги — в `observed.md`:** на каждую поставку, чьи проверки прошли в сессии, —
   `delivery/archive/<поставка>/observed.md` по шаблону канона A.17: id, что обещано, что на телефоне, вердикт
   (ПОДТВЕРЖДЁН / НЕ ПОДТВЕРЖДЁН) и метрики (p95, footprint, время окна). Числа — из файлов `local/test-session/<дата>/`,
   слов и записей — нет. Закрытое наблюдение уходит строкой из `delivery/OBSERVATIONS.md` той же правкой. Проверка не
   прошла — `blockers:` и эскалация к ведущему, а не правка числа порога.
