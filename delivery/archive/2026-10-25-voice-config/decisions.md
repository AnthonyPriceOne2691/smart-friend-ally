# Decisions

- 2026-10-23 · выбрал разбить V4b на V4b1 `voice-config` и V4b2 `voice-app` вместо одной поставки, потому что по
  правилу ведущего «план +50%, стоп 780» V4b — ≈ 1 100 строк при пределе 800.
- 2026-10-23 · выбрал один манифест `voice.json` для приложения и команды копирования вместо двух, потому что имена и
  байты не должны расходиться.
- 2026-10-23 · выбрал пометку строк с sha256 фразой для сканера секретов вместо записи в `.secrets.baseline`, потому что
  снимок секретов в проекте пуст, а sha256 — не секрет: пометка видна в самой строке.
- 2026-10-23 · выбрал команду копирования на Python вместо bash, потому что smoke бежит в CI на Linux, а распаковка и
  sha256 на bash расходятся между macOS и Linux.
- 2026-10-23 · выбрал копировать группу `accent` уже сейчас, но не проверять её в приложении, вместо ожидания V3,
  потому что так велел ведущий (заметки V3b и V3c), а приложение не должно неметь без файлов, которыми не пользуется.
- 2026-10-25 · выбрал в смоке S8 подмену того же размера вместо подмены другим содержимым другой длины, потому что
  мутант «сверять только байты» выжил на прежнем смоке: подмену другой длины ловит и сверка размера, sha256 видна
  только на подмене того же размера.
- 2026-10-23 · выбрал пометку строки манифеста значением `"// pragma: allowlist secret"` вместо голой фразы, потому что
  detect-secrets в JSON пропускает строку только с пометкой после знака комментария: голая фраза в значении не сработала
  (проверено хуком на `voice.json`).
