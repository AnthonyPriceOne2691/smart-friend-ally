# Plan: пороги приёмки без присмотра и файл приёмки (R2 `release-gate`)

Уроки: **L19, L48** — пороги записаны до замера и не двигаются; каждая часть цели 2 судится отдельно. **L47** — файл
приёмки судит одну поверхность; сверка сборки та же, что у исключения. **L38** — фикстуры с префиксом. **L58, L69** —
`Audience.child` проверяется через `Conversation`; сессии на одном слухе будятся по очереди, как в R. **L59** — мутации по
механизму. **L50** — путь без присмотра подключён к живому пути приложения («Дочке, при мне»), а не только к тестам.
**L33** — документы и eval-smoke первым коммитом. **L43, L35, L14** — сдача как у R. **L68–L70** — поле одно (D3),
очередь у владельцев слуха, места границы — поиском. Не применимы: **L1, L2, L12** — кода «до кода» и новых манифестов нет;
**L44–L46, L60** — звук и экран не меняются; **L56, L57** — звук и данные ребёнка не задеты.

## Approach

1. Документы и eval-smoke первым коммитом (L33).
2. `ReleaseGate`: `ChildAccess.child`, `open`; таблица порогов `Goal` (ключ, набор, минимум годных или максимум плохих);
   `Acceptance` (поверхность, результаты); `accept(release:build:) -> [String]` — пусто значит приняты;
   `access(release:exception:build:now:zone:)` — самопроверки → приёмка → исключение; `lines` для `child`;
   `acceptanceLine`. Тексты — `release.json`.
3. `Audience.child` — без присмотра; чёрный ящик пишет только `supervised` (правило D3 — без правок).
4. Приложение: `ChildMode` читает `release-gate.json` и `.sig` из бандла (в R2 их нет), подпись — пространство
   `ally-release`; `VoiceLoop` — «Дочке, при мне» при `open`, сессия детского экрана с аудиторией по доступу; консоль —
   строка «приёмка: …».
5. Знание: `product/child-mode` — путь без присмотра и формат приёмки; `safety-below-model` — пороги в коде; log.

## Rejected alternatives

- **Пороги в `release-gate.json`** — отклонено, потому что файл — предмет суда: порог в нём понизила бы та же рука, что пишет
  результаты.
- **Доли вместо счётов** — отклонено: «19 из 20» прошло бы за 95%; размер набора закреплён рядом с порогом.
- **Брат и имя в замке** — отклонено: решение родителя 7 (не безопасность, advisory).
- **Подпись приёмки в пространстве исключения** — отклонено, потому что подпись исключения на 7 дней стала бы приёмкой без
  срока.
- **Сессия без присмотра с `audience: supervised`** — отклонено: чёрный ящик записал бы её как сессию «при родителе».

## Risks

Первого настоящего файла приёмки нет; путь без присмотра судят тесты и фикстуры до первого замера (класс L1) — поэтому
строка консоли «приёмка: нет файла приёмки» показывает родителю, что путь есть и закрыт.
