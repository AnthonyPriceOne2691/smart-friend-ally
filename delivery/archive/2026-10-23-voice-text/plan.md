## Approach

1. **Протокол** (`StressPlacer.swift`): `protocol StressPlacer: Sendable { func place(_ text: String) throws -> String }` —
   ответ: вход с «+» перед ударной гласной (формат RUAccent), «ё» может быть восстановлена.
2. **Слово с ударением** (`SpokenWord.swift`): буквы и номер ударной гласной (`stress: Int?`, считая гласные
   «аеёиоуыэюя» с нуля); разбор «+»-формы; знак U+0301 после гласной номер `stress`, если гласных ≥ 2 и нет «ё»;
   перенос регистра первой буквы на замену.
3. **Таблица** (`SpeechTextTable.swift`, `Resources/speech-text.json`): `stress`, `names`, `words`, `endings` (`end`,
   `to`, `unstressed`, `except`), `parts`. Загрузка — `bundled()` из ресурса пакета и `init(json:)`; конструктор с
   разделами для фикстур. Проверка при загрузке: у `words`, `endings`, `parts` число гласных замены равно исходному; у
   `stress` буквы формы равны ключу и ударная одна. Нарушение — `SpeechTextError` с названием правила.
4. **Переписывание** (`Respelling.swift`): ключ — слово строчными. `names` — замена целиком, дальше правила не идут;
   `stress` — только номер ударной; затем `words` (слово целиком) либо самое длинное подходящее окончание вне `except`
   (вариант `unstressed`, если ударение известно и стоит не на последней гласной; неизвестное ударение — как безударный
   конец) и все `parts`. Число гласных сохраняется, поэтому номер ударной переносится как есть.
5. **Конвейер** (`SpeechTextPipeline.swift`): `prepare(_ phrase:) throws -> SpeechText`. Расстановщик получает фразу как
   есть (Z12); слова его ответа — серии кириллических букв с «+» перед буквой — проходят шаги 4 и 2 и получают знак;
   прочие знаки ответа идут в `engine` без изменений. `SpeechText`: `shown` — вход как есть, `engine` — вход движка,
   `trace` — `marks`, `pinned`, `respelled` (Codable, без слов).
6. **Данные V2** (`speech-text.json`): `stress` «здорово» → «зд+орово»; `names` «элли» → «+элли»; `words` «сегодня» →
   «севодня»; `endings` «ого» → «ово» / «ова», «его» → «ево» / «ева», исключения у «ого»: «много», «немного», «строго»,
   «дорого», «убого», «полого», «ого»; `parts` пуст до второго круга.
7. **CI:** `LINT_SWIFT_PACKAGES` + `Packages/AllySpeechText` (джоба `swift`); третий прогон jscpd в хуке
   `jscpd-dry-gate`; `Packages/AllySpeechText/.build` — в `excluded` SwiftLint; правки записаны в `adapted.json` и в
   строку jscpd карты ролей.
8. **Знание:** concept `knowledge/engineering/speech-text.md` (Design, `implementation:` — исходники и таблица пакета),
   `engineering/index.md`, `references/repo-map.md`, `knowledge/log.md`; места, где описан текстовый путь к голосу,
   находит поиск (L16), а не план.

- `SpeechTextTests.swift`: Z8–Z13, у каждого тест-блока id в первой строке тела.
- Двойник расстановщика — словарь «+»-форм с переносом регистра, запоминает полученные тексты (Z12).
- Свойство Z11: 500 слов с зерном 42 — формы словаря тестов (примеры, исключения, основы × окончания) и слова из слогов
  с окончаниями и словами таблицы; судятся число гласных и номер гласной со знаком на выходе; таблицы — пакета и фикстура
  со всеми видами правил.
- Мутации в ту же сессию, файлы восстанавливаются (П30): «исключение не сработало» (Z10, красный на каждом из семи),
  «переписывание до расстановщика» (Z12), «знак по номеру буквы, а не гласной» (Z11), «знак на „ё“» и «знак на
  односложных» (Z8), «словарь под расстановщиком» (Z9), «след несёт слова» (Z13), «таблица без проверки числа гласных»
  (Z11), «вариант окончания без учёта ударения» (Z10).

## Rejected alternatives

- **Ставить ударения после переписывания** (расстановщик видит «севодня») — отклонено: Z12; расстановщик не знает
  переписанных форм («севодня», «но́вова» — не слова), омографы решаются по исходному тексту.
- **Протокол отдаёт U+0301 вместо «+»** — отклонено: «+» — родной формат RUAccent, V3 отдал бы его без перевода, а
  конвейер всё равно разбирает слово на буквы и номер ударной; знак ставится один раз, в конце.
- **Переписывание регулярками по тексту с «+» внутри** — отклонено: знак сдвигается при замене букв, и инвариант «та же
  гласная» пришлось бы ловить после; номер гласной и проверка числа гласных при загрузке держат его построением.
- **Один общий список исключений на все правила** — отклонено: исключения -ого/-его не касаются будущих «сч» и «-тся»;
  исключение живёт при своём правиле.
- **Правила в коде** — отклонено: решение серии 5 и стейкхолдер «второй круг» — строки данными без правки кода.
- **Запасной путь при отказе расстановщика внутри конвейера** — отклонено для V2: у него не было бы вызывающего (L50);
  что звучит при отказе (Milena, текст без знаков), решает V4.
- **Хэш таблицы в следе** — отклонено: журнал V4 несёт версии движка, пресета и ORT (Z21); версия таблицы — когда разбор
  чёрного ящика её попросит.

## Risks

- **Исключения видят только виденное (L28)** — см. спеку; правится строками данных.
- **Формат ответа расстановщика** — договор с V3: всё сверх «+» и «ё» дойдёт до движка.
- **Регистр.** Замена получает заглавную первую букву, если она была у слова; слово из одних заглавных станет «Слово» —
  для голоса разницы нет, на экран идёт `shown`.
- **Параллельно V1** правит строку jscpd — конфликт сложением (L35); **второй круг** может прийти во время поставки —
  строки и тесты добавляются отдельным коммитом с тестом на каждую.
