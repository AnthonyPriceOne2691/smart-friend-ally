# Plan: контракт хода

Уроки архива: **L8** — у каждого правила проба-нарушитель и хитрая чистая; **L19** — проверки замораживаются до
прогона; **L25** — правило исполнителя принимается полным прогоном, а не на глаз; **L26** — ноль у прибора на Swift —
повод для пробы, а не итог; **L27** — паритет по корпусу находит дефекты эталона, правка — в эталоне и в порте сразу. **L28, L29, L30** — уроки этой поставки (handoff): проверка списком видит только виденное; две подписанные цели могут быть несовместимы на ответах модели; парное слепое судейство отделяет эффект правки от разброса судей.

## Approach

1. **Перенос с паритетом.** Правила содержания и отбор предложений из `local/spike/discipline/output_filter.py`
   (функции `split_sentences`, `split_long`, `fits`, `select`, `attachment`, `danger_howto`, указатель на взрослого,
   запасной ответ) — в `TurnContract` пакета `AllyDiscipline`; данные — `Resources/contract.json`. Новые правила
   (режим прощания, вопрос после запрета, запрет по опасности вместо общего «это опасно») — сначала в эталон на Python,
   потом в Swift; фикстуры паритета — те же входы, что у `Repair`, плюс поле с выходом контракта.
2. **Поток:** `TurnContract(mode:)`; `first(_:)` — первое предложение после `Repair` и правил, отдаётся сразу;
   `finish(_:)` — остальной ответ: отбор в лимитах, указатель на взрослого, запасной ответ. Озвученное не меняется.
3. **Fail-closed:** загрузка `contract.json` прогоняет пробы-нарушители из самих данных; хоть одна не поймана — только
   заготовки, в журнале отказ.
4. **Журнал:** `TurnRecord` — id правил, хэш данных, источник ответа (модель или заготовка); слов девочки нет по
   построению — контракт принимает её реплику только для режима, в журнал она не идёт.
5. **Замер:** исполняемый таргет `discipline-replay` читает JSONL сохранённых ответов, пишет итог; замороженные
   проверки стенда (`form_rules.py`, `dialog_rules.py`, `erudition_rules.py`, `peer_rules.py`, `hazard_judge.py`) и
   слепые судьи-агенты судят итог против сырых ответов.

## Stack / boundaries

- Swift 6.4, только Foundation; CI на Linux (джоба `swift`). Приложение и вызов модели — не здесь.

## Risks

- Отбор срезает суть ответа «почему» (прототип: эрудиция 43 → 38) — режим `why` со своими лимитами, замер K10.
- Новая проверка «вопрос после запрета» срезает обычный вопрос после «не бойся» — запрет определяется списком, а не
  частицей «не»; проба-двойник «Не бойся! Хочешь, споём?» обязана пройти.
- Предохранитель 800 строк: бюджет — исходники ≤ 380, `contract.json` ≤ 100, тесты ≤ 220, генератор фикстур +25,
  инструмент прогона ≤ 35.

## Rejected alternatives

- **Перенести весь фильтр одной поставкой** — отклонено, потому что адрес и телефон, секреты и честность «ты живая?»
  тянут ещё ~250 строк и упираются в предохранитель 800; они идут с маршрутизатором, где живёт режим безопасности.
- **Отбирать предложения после того, как модель допишет ответ** — отклонено, потому что первый звук ждал бы весь
  ответ (p95 до первого звука 1,9 с вырос бы на время генерации); первое предложение звучит сразу, остальные модель
  догенерирует быстрее, чем звучит первое.
