# Spec: контракт хода — что из ответа модели доходит до голоса

> Вторая поставка дисциплины (решение родителя 2026-10-18: «вязать модель кодом», цели приёмки подписаны —
> `knowledge/engineering/safety-below-model.md`). Первая (`swift-contour`) дала ремонт формы `Repair`. Эта переносит в
> Swift правила содержания и отбор предложений из прототипа на Python (`local/spike/discipline/output_filter.py`,
> 146 самотестов, мутации 44 из 44) и добавляет три правила по целям родителя. Приватность и секреты, маршрутизатор и
> готовые ответы до модели — следующая поставка.

## Problem

Ответ модели сейчас доходит до голоса целиком: сырая v2.4 даёт больше трёх предложений в 51 ответе из 120, два
вопроса — в 33, фразы привязанности («я буду ждать тебя») на просьбу не уходить, вопрос на прощание и опасное
продолжение после верного запрета («расскажи, какие ещё штучки ты нашла в шкафу?»). Промпт этого не держит (L25).
Прототип фильтра на Python держит, но живёт вне git и не входит в приложение.

## Users / stakeholders

- Дочь: слышит короткий ответ без давления, без «приходи ещё» и без вопросов после «нельзя».
- Родитель: цели 3 и 4 держит код; запасной ответ на опасное — конкретный запрет, а не общее «это опасно».
- Поставка приложения: голосовой цикл зовёт контракт на каждом ответе; первое предложение звучит сразу.

## In scope

1. `TurnContract` в пакете `AllyDiscipline`: режим хода (`talk`, `why`, `goodbye`) со своими лимитами; первое
   предложение проверяется и отдаётся сразу; остальные отбираются в пределах лимитов (не больше трёх предложений,
   одного вопроса, слов на предложение и на ответ) — первое всегда, затем указание на взрослого и защитное
   действие, затем остальные по порядку; длинное предложение режется по союзу.
2. Правила содержания (перенос): фразы привязанности (с исключениями «я не скучаю» и «никуда не уходи, стой на
   месте»), «как сделать опасное» (огонь, спички, плита, розетка, таблетки, окно — с поощрением, без запрета).
   Первое нарушение обрывает ответ: дальше ничего не звучит.
3. Новые правила: в режиме прощания вопросов нет; после предложения с запретом вопросы не звучат (кроме указания
   «покажи маме, хорошо?»); из двух вопросов звучит последний; в режиме «почему» встречный вопрос и похвала за вопрос
   не занимают место сути; запасной ответ на «как сделать опасное» — готовый запрет по найденной опасности (спички,
   плита, горячее, розетка, таблетки, окно, нож), а не общее «это опасно».
4. Ничего не осталось — заготовка режима (fail-closed); проверка данных контракта при загрузке: заведомые нарушения
   обязаны ловиться, иначе контракт отвечает только заготовками.
5. Журнал хода: id правил, хэш данных контракта, «модель или заготовка» — без слов девочки.
6. Данные — `contract.json` одной копией для Swift и стенда; инструмент прогона сохранённых ответов через контракт
   (замер на замороженных наборах).

## Out of scope

- Адрес и телефон, секреты, «ты живая?» — следующая поставка вместе с маршрутизатором и готовыми ответами по
  опасностям до модели; там же режим безопасности и цели 1, 2 и 7.
- Перегенерация ответа моделью — её делает голосовой цикл приложения; контракт говорит, что звучать нечему.
- Реестр «правило промпта → исполнитель» полем STATUS — с объявлением `model_surface` в поставке приложения; до неё —
  таблицей в концепте `safety-below-model`.
- Вопрос в конце сверх трёх предложений (цель 4 после уточнения родителя 2026-10-18) — отдельная поставка вместе с
  приёмкой живости K11: правило добавляет около 18 строк, а дифф этой поставки — 799 из 800.

## Acceptance (observable)

Голосом идёт только то, что прошло контракт; на замороженных наборах ответов v2.4 нарушений целей 3 и 4 ноль, а
эрудиция, брат, имя, память и безопасность не хуже сырой модели. Живость (K11) замерена и не выполнена — по решению
родителя 2026-10-18 её закрывает следующая поставка: «вопрос в конце может идти четвёртым» (уточнение цели 4).

## Non-functional

- Только Foundation; регулярки компилируются один раз; первое предложение — без ожидания остальных.
- Исходники ≤ 300 строк на файл, сложность функции ≤ 8; предохранитель §3.4 — 800 строк диффа.
