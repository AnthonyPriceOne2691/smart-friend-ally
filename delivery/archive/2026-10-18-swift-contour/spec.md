# Spec: Swift-контур и ремонт текста — первый код продукта

> Решение родителя 2026-10-18: дисциплину модели «вязать кодом» — контракты, оракулы, контроль судьи — и после неё
> собирать приложение. Это первая из трёх поставок дисциплины: Swift-контур с первым модулем, затем контракт хода,
> затем маршрутизатор до модели (замер прототипа: `knowledge/engineering/persona-eval.md`,
> `knowledge/engineering/safety-below-model.md`). Цель согласована словами, примеры приёмки родитель ещё не видел,
> поэтому `human_ok_spec: deferred`.

## Problem

Кода продукта нет, поэтому роли качества для Swift объявлены `n/a` «до первого кода» (19 ключей в
`scripts/lint/na-expiry.json`), и первый `.swift` краснит коммит и CI, пока каждое объявление не решено. Исполнители
ниже модели живут прототипом на Python вне git (`local/spike/enforcers/`), а временная копия части правил — в зонде на
телефоне. Без пакета в репозитории нечего проверять гейтами и не на чем строить контракт хода.

## Users / stakeholders

- Дочь: слышит ответ после ремонта — без разметки, латиницы, цифр и взрослых обращений.
- Родитель: решение «без „моя хорошая“, только имя» держит код, а не промпт.
- Следующие поставки: контракт хода и маршрутизатор строятся на API `Repair`.

## In scope

1. SPM-пакет `Packages/AllyDiscipline` (только Foundation, iOS 17 и macOS 14, собирается на Linux): модуль `Repair` —
   разметка и эмодзи, символы, латиница в кириллицу, цифры словами, отметка телефонного номера, взрослые обращения и
   заглушки вида «[Имя девочки]». Данные — одной копией в ресурсе `repair.json`.
2. Тесты: проба-нарушитель и хитрая чистая проба на каждое правило, абляция каждого правила, паритет с эталоном на
   Python на реальных ответах модели, метаморфная проверка.
3. Swift-контур: SwiftLint-ратчет со сложностью, file-length с маской `*.swift`, `swift test` и покрытие в CI на
   Linux, решение по каждому из 19 ключей `na-expiry` — подключить гейт или переобъявить `n/a` с причиной, верной при
   коде.

## Out of scope

- Контракт хода (режимы, выбор предложений, правила содержания, восстановление) и реестр правило→исполнитель —
  следующая поставка. Она же решает, что звучит вместо отметки номера телефона: ремонт только ставит отметку, сам номер
  до голоса не доходит.
- Маршрутизатор до модели и готовые ответы по опасностям — поставка после неё.
- Приложение, голосовой цикл, промпт и пин модели в репозитории — поставка приложения.

## Acceptance (observable)

`swift test` пакета проходит локально и в CI; гейты Swift видят код и краснеют на нарушении; `check_na_expiry.py`
зелёный без единого ключа под маской `*.swift`; доктор контура не зовёт подключённые гейты `DEAD`.

## Non-functional

- Пакет без внешних зависимостей; регулярные выражения компилируются один раз.
- Исходники — не больше 300 строк на файл, сложность функции — не больше 8 (мягкий порог канона; жёсткий 10).
- CI на Linux (macOS-раннер ×10 по цене, CQG §8.7); сборку для iOS проверяет поставка приложения.
