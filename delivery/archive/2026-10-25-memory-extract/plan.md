## Approach

1. **Ресурсы:** `extract.system.ru.md` (правила разбора по справке B2 без событий и планов — их память пока не хранит),
   `extract.user.ru.md` (шаблон запроса с подстановками), `extract.json` (шаблон ответа, пример Милы и ответ к нему,
   текст повтора, причины, подписи разговора, «да»-слова, служебные слова, параметры 0,2 / 42 / json).
2. **`ExtractPrompt`:** системный текст — ресурс как есть; запрос — подстановка шаблона, примера, «что уже известно»
   (она, близкие с отношением, питомцы с видом, придуманное — имена и возраст словами из `memory.json`) и разговора
   «N. Девочка: …» / «Элли: …» по номерам ходов; FNV-1a 64 по байтам системного текста и запроса.
3. **`ModelAnswer`:** вырезка объекта JSON из ответа, разбор по шаблону, мусор — причина из ресурса.
4. **`Anchors`:** слова значения (без служебных, числа — по значению); опора в её реплике N, если сходны не меньше
   половины слов значения; иначе лучшая другая её реплика — «код»; иначе её «да» с репликой Элли перед ним —
   «согласилась»; иначе «без опоры».
5. **`MemoryStore.remember(_:model:)`:** запрос → модель → разбор, при мусоре один повтор (ответ модели и «Ответь ещё
   раз» с причиной), при втором мусоре — `failed`; кандидаты с опорой — `write` одной транзакцией с её репликами
   (`heard`); итог — `Extraction` (статус, хэш, параметры, попытки, кандидаты, отброшенное без значений, отчёт записи).
6. **Знание:** `engineering/memory` — разбор и чего ещё нет; `safety-below-model` — раздел правил промпта разбора;
   `log.md`.

## Rejected alternatives

- **Номер реплики только у подробностей, как в справке B2** — отклонено: имя и возраст без номера требуют своих
  поисков строки (по имени, по числу); единая форма «N: …» даёт одну опору на все значения.
- **Схема JSON для грамматики в ресурсе сейчас** — отклонено: двойнику она не нужна, вызывающего нет (L50); параметр
  «грамматика JSON» пишется в итог, схему или GBNF подключает тот, кто зовёт E4B (`memory-quality`, `memory-app`).
- **Разбор пишет сам, без итога** — отклонено: родителю и журналу нужны «не разобрана» с причиной, хэш и параметры.

## Test / eval strategy

- `ExtractTests` — M26, M27, M28 тремя тестами с метками; двойник модели отдаёт ответы по очереди и запоминает запросы.
  Мутации: «повтора нет» (M27), «опора только по номеру модели» (M28 — «лепить» уходит), «согласие не проверяется»
  (M28 — «зоопарк» записан), «хэш без запроса» (M26).
