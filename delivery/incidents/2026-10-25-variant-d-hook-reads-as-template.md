## Симптом

Рецепт §7.1a несёт строку `entry: "тексты контура в git не кладутся: git rm --cached` плюс путь в угловых скобках
и ссылку на §7.1a. Это обычный скаляр в кавычках. Мета-гейт вырезает из yaml только блочные скаляры (`|`, `>`), а
слово в угловых скобках для него — форма шаблона канона. Коммит с рецептом, вписанным дословно, отклоняет хук
`gate-coverage`:

```text
ERROR: незаполненный шаблон в конфиге контура — процедура развёрнута наполовину:
  ✗  .pre-commit-config.yaml: <путь>
```

Сканер судит и строки-комментарии: комментарий, который объясняет замену и упоминает тот же плейсхолдер, краснит
точно так же.

## Воспроизведение (Ally, 2026-10-25, канонный код без правок)

1. Ветка `chore/canon-variant-d`, `docs/canon/` снят с индекса, хук из §7.1a вписан в `.pre-commit-config.yaml`
   дословно. `git commit` отклонён: хук `gate-coverage`, вывод выше.
2. `STRICT=1 bash scripts/lint/check_gate_coverage.sh` даёт exit 1 с той же строкой.
3. В сообщении вместо плейсхолдера — команда `git rm -r --cached docs/canon`. Тот же прогон: `gate-coverage: OK — 21
   скрипт(ов), подключено 11, осознанно нет 10`.

Оракул согласия канона `tests/test_foreign_repo_is_local_only.py` проверяет у рецепта маску `files:`, но не прогоняет
по нему мета-гейт. Поле, из которого рецепт взят (portfolio-site, `9b34946`), писало сообщение без плейсхолдера
(«Убери из индекса: git rm -r --cached docs/canon»). Плейсхолдер появился, когда канон обобщил сообщение.

## Предложение (решает судья)

В рецепте §7.1a заменить путь в угловых скобках командой снятия (`git rm -r --cached docs/canon`) или формой без
скобок, как `ПРОЕКТ` в соседних командах карты. В оракул согласия добавить прогон: рецепт, вписанный в
`.pre-commit-config.yaml` тестового стенда, проходит `check_gate_coverage.sh`. Обратный прогон — строка с плейсхолдером
краснеет.
