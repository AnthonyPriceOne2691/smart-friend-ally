# Инцидент: под вариантом D доктор называет развёрнутый канон «не развёрнутым», а пропавший локальный снимок не видит никто

- **Дата:** 2026-10-25 · **Нашедший:** agent:claude-code (сессия smart-frend-ally, поставка `canon-variant-d`) · **Хозяин:** smart-friend-ally
- **Канон:** `scripts/lint/doctor_versions.py::check_canons` и `scripts/lint/doctor_layout.py::check_divergence_from_canon`
  (`cqg@2.74`; строка «файла нет — слой не развёрнут» та же в `cqg@2.83`); `AGENT_STACK.md` §7.1a — цена варианта D,
  названная для доктора; `field/fleet/apply_update.py::revendor` (Prepare)

## Симптом

Ally перевёл снимок канонов на вариант D: `stack-selftest: external` в `delivery/STACK-ACCEPTANCE.md`, `docs/canon/` вне
git. В CI, где каталога нет, доктор пишет три вещи:

- `ABSENT канон <имя> — файла нет — слой не развёрнут`, по разу на каждый из четырёх канонов. Слой развёрнут, тексты
  лежат локально по решению. Это тот же класс, что закрыт в `cqg@1.73` для варианта C: доктор говорит «бедность» там,
  где всё на месте. `ABSENT` прогон не роняет, а приёмка §6 читается по доктору.
- `SKIP провенанс снимка — нет docs/canon/VENDORED.json — провенанс снимка не записан, сверять нечем (§5 шаг 11)`.
  Совет ведёт на шаг варианта C.
- Сверка конфигов с каноном (`.pre-commit-config.yaml`, `quality.yml`) пропадает без строки. Со снимком обе дают
  `WEAK … адаптирован намеренно`, без снимка доктор о них молчит. Тела скриптов судятся по замку, конфигов в замке нет.

При этом §7.1a называет ценой D для доктора то, чего уже нет: «доктор печатает `SKIP` с причиной „состав сверить
нечем“». Замер: `AUTO состав контура — развёрнуто 56 из 57`, состав берётся из замка с `cqg@2.44`.

Второй симптом — сам перевод C → D. Коммит `git rm -r --cached docs/canon` при слиянии удаляет локальный снимок в
каждой другой копии репозитория: в основном клоне после squash-мержа, в ворктри после слияния main, на другой машине
после pull. Git удаляет отслеживаемые файлы, которые входящий коммит убрал. `apply_update.py::revendor()` каталога не
находит, читает это как вариант B (`return []`), и следующий накат снимок не разложит. В копии без снимка доктор
печатает те же четыре `ABSENT`: пропавший снимок неотличим от «B по выбору» и от «не развёрнуто».

## Воспроизведение (Ally, 2026-10-25, канонный код без правок)

1. Доктор с env джобы `gates`. Ворктри с локальным снимком: `AUTO 47 · WEAK 13 · ABSENT 4 · TOOL 3 · SKIP 4 · DEAD 0`.
   Чистый checkout того же коммита (`git worktree add --detach`, каталога `docs/` нет): `AUTO 42 · WEAK 11 · ABSENT 8 ·
   TOOL 3 · SKIP 5 · DEAD 0`. Разница построчно: четыре канона `AUTO → ABSENT`, провенанс `AUTO → SKIP`, две строки
   `WEAK расхождение с каноном` исчезли.
2. Свежий клон main (в git 9 файлов `docs/canon/`), строка `/docs/canon/` в `.git/info/exclude`, `git merge --squash`
   ветки `chore/canon-variant-d` и коммит: `docs/canon/` нет. Восстановление `git restore --source=<коммит удаления>^
   --worktree -- docs/canon` вернуло 9 файлов: `git status` чист, `git ls-files docs/canon` пуст, sha256 сошлись 7 из 7,
   `--check-local` — 0 и 0.

## Что сделано в Ally (канон не правился)

- `DEAD 0`, шаг доктора в CI зелёный. Четыре `ABSENT` и `SKIP` провенанса приняты как названная цена D: строка в
  остатках `delivery/STACK-ACCEPTANCE.md`, оба замера — в verify-report поставки.
- Команда восстановления основного клона после мержа передана ведущему.
- Запись `kind: upstream-candidate` у `scripts/lint/doctor_versions.py` в `scripts/lint/adapted.json`.

## Предложение (решает судья)

Доктор читает объявление `stack-selftest:`, как уже читает его шаг CI. Канон без файла при объявленном B/D получает
не `ABSENT … слой не развёрнут`, а строку «вариант B/D: тексты вне git (объявлено)». `SKIP` провенанса идёт без ссылки
на §5 шаг 11. Сверка конфигов без снимка даёт `SKIP` со списком того, что не сверено. В §7.1a обновить цену D для
доктора (состав — по замку, цена ушла в каноны, провенанс и конфиги). Для перевода C → D назвать, что другие копии
теряют снимок при слиянии, дать команду восстановления и сказать, что `apply_update` отсутствующий снимок не
раскладывает. Проба: чистый checkout с объявлением — строки «слой не развёрнут» нет. Обратный прогон: без объявления
`ABSENT` остаётся.
