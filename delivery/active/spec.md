# Spec: голос Элли в приложении — V4a `voice-fx` и V4b `voice-app` (серия голоса)

> Продолжение серии голоса под подписью родителя 2026-10-23 (спека `68202f0`). V4 там описана примерами Z19–Z26. После
> подписи третий круг образцов (2026-10-23) изменил стадию обработки: родитель выбрал своё PSOLA и эквалайзер вместо
> передискретизации, имя для синтеза — «Э́льли». По пределу 800 строк V4 идёт двумя поставками: **V4a `voice-fx`**
> (обработка, Linux) → **V4b `voice-app`** (приложение, телефон). Новые примеры — Z27–Z30 (V4a) — на подпись; Z19–Z26
> переносятся в V4b таблицей без изменения смысла, с правками ниже. Расстановщик RUAccent (V3) ведёт исполнитель V2; до
> него приложение говорит через протокол `StressPlacer` с заглушкой.

## Что изменилось с подписи 23.10

1. **Стадия высоты и формант — своё TD-PSOLA и эквалайзер.** Порт инструмента стенда `psola_c` (local/spike/voice-samples-2):
   YIN на сигнале, прореженном в 4 раза; метки периодов по пикам после фильтра 900 Гц; сдвиг формант — передискретизация
   окном sinc из 8 отсчётов; наложение с окном Ханна. Эквалайзер — биквады RBJ (полки и пик). AVAudioUnitTimePitch и
   передискретизация отклонены третьим кругом (UTMOS 1,47 и 2,3).
2. **Пресет — из третьего круга**, одной строкой конфига: стиль, скорость синтеза, шаги, сдвиг высоты и формант,
   полосы эквалайзера. Кандидаты родителя: «Девочка» — F2, 0,9, PSOLA +8 / +4, «light» (полка 250 Гц −3 дБ, пик 4 кГц
   +2,5 дБ); «По образцу» — F2, 0,9, PSOLA +9,5 / +3,5, «ref» (пик 2,5 кГц +3,5 дБ, пик 4 кГц +1,5 дБ). Выбор
   родителя меняет строку.
3. **Имя для синтеза — «Э́льли»** из `speech-text.json` (V2); экран и журнал — «Элли».
4. **Расстановщик — протокол `StressPlacer`.** До V3 — заглушка, которая отдаёт фразу без ударений: знаки ставят только
   закреплённые слова и имена таблицы V2. RUAccent встаёт в протокол без правки приложения.

## V4a `voice-fx` — In scope

- Пакет `Packages/AllyVoiceFX` (только Foundation, Linux-джоба `swift`, покрытие ≥ 70%): C-ядро PSOLA (порт `psola_c`),
  эквалайзер на Swift, `VoiceFX.process(_:rate:)` по пресету.

## V4a — Out of scope

- Приложение, воспроизведение, первый звук, порт звука, файлы голоса (V4b).
- Расстановщик RUAccent (V3, исполнитель V2).

## Non-functional

- PSOLA — свой код без GPL (порт собственного инструмента стенда `psola_c`); эквалайзер — формулы RBJ.
- Только Foundation и C: пакет собирается и тестируется на Linux, покрытие ≥ 70% (джоба `swift`).
- Форма — по CQG: файл ≤ 500 строк, функция ≤ 50, сложность ≤ 8; маска гейта длины видит `*.c *.h`.
- Данные: в тестах только синтетические сигналы; эталон Z30 — сгенерированный звук в `~/models`, не в git.

## Risks

- **Цена PSOLA на телефоне.** На Mac — миллисекунды на секунду звука (стенд); на телефоне её меряет Z22 V4b.
- **F0 меряется на входе** — взрослом F2 около 200 Гц, а не на детски-высоком выходе: YIN в диапазоне 70–700 Гц.
- **Объём.** Перенос с C на C почти один в один, план ≈ 420 строк; стоп-линия 780.
