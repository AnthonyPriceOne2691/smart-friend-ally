## Problem

- **Ядро без вызывающего (L50).** `BlackBox` в AllyCore слит, но приложение его не зовёт: на телефоне нет ни одного
  файла ящика, сток следа — только `TraceFile` без слов.
- **Её звук не доходит до ящика.** Буфер, который ушёл в распознаватель, живёт внутри `Phrase.feed` и наружу не отдаётся.
- **Нечем выгрузить и стереть.** Нет команды на Mac со сторожами git и iCloud; в консоли нет строки ящика и кнопки
  стирания.

## Users / stakeholders

- **Родитель:** в консоли — строка ящика (сколько записано, предел, «выгрузи на Mac»); кнопка «Стереть чёрный ящик» с
  подтверждением; на Mac — `python3 scripts/blackbox.py pull` и `erase` одной командой.
- **Дочь:** ничего не меняется; пишутся только её детские сессии при родителе (`audience: supervised`, исключение R).
- **Следующие поставки:** D3.3 (голос Элли — лента в тот же ящик), разбор на Mac, шаг 3.

## In scope

1. **Хранилище на телефоне** — `App/Sources/BlackBox/PhoneDisk.swift`: `Library/Application Support/BlackBox`,
   `NSFileProtectionComplete` на каталоге и каждом файле (`.atomic`, `.completeFileProtection`), пометка «не в бэкап» с
   чтением обратно; `isPrivate` — обе прочитаны.
2. **Её звук у распознавателя** — крючок в `Phrase.feed` отдаёт отсчёты преобразованного буфера, ровно тех, что ушли в
   анализатор; строка консоли называет формат распознавателя. `PhoneListener` собирает реплику (`Utterance`: отсчёты,
   частота, времена слушания) и отдаёт её ящику до текста.
3. **Проводка** — `VoiceLoop`: `BlackBox` вторым приёмником через `TraceFanOut` рядом с `TraceFile`; строка ящика и
   кнопка стирания в консоли; строка ящика — и в журнал (`os.Logger`, без слов): так её видно в
   `devicectl … --console`, пока консоль закрыта детским экраном. Ядро получает `held()` — сколько сессий и байт в ящике
   (для подтверждения).
4. **Команда на Mac** — `scripts/blackbox.py pull|erase --device <UDID>` со сторожами git и iCloud, сверкой байт и
   FNV-1a, стиранием только сверенного; смоук S9 на двойнике `devicectl`.
5. **Знание:** `ops/black-box` (D3.2 сделана, `implementation:` — файлы приложения и команда), runbook
   `engineering/voice-loop` (выгрузка и стирание командами), `ops/child-data` (сторожа выгрузки в механике).

## Out of scope

- Переключатель «дочь при родителе», исключение и детский экран — R `child-lock` (ответ ведущего 2026-10-23); D3.2
  только читает `audience`.
- Голос Элли с выхода — D3.3 после поставки голоса; до неё `elly_audio` — `not_recorded`.
- **Начало её речи** (`pause_before_speech`, `her_speech`) — аудиопуть D1.2 его не отдаёт, правка `App/Sources/Audio/`
  была бы третьим рисковым путём; в записи пока есть длительность клипа, хвост, распознавание и «конец речи → первый
  звук». Вернётся с поставкой слуха (детектор конца хода) или D6.
- Разбор на Mac, эталоны вслепую, шаг 3.

## Acceptance (observable)

На телефоне родителя детская сессия при родителе оставляет в закрытом каталоге вне бэкапа записи ящика — по одной на
строку следа — с её звуком ровно из буфера распознавателя; консоль показывает строку ящика и стирает его по
подтверждению; одна команда на Mac выгружает и сверяет, другая стирает только выгруженное; сессии консоли файлов не
оставляют.

## Non-functional

- Сети нет: правило SwiftLint `no_network` и оракул артефакта на собранном `.app`. Новых зависимостей нет; команда на
  Mac — stdlib Python 3.
- Данные: слова и звук — только в ящике на телефоне и в `local/blackbox/` на Mac; журнал `os.Logger` — только строка
  ящика и счёт отсчётов, без слов. Смоук S9 создаёт синтетические файлы только во временных каталогах.
- Форма: файл ≤ 500 строк, функция ≤ 50, сложность ≤ 8; строки по-русски короче 40 знаков после первой кириллической
  буквы (`inline_prompt`).
- Предохранитель: ≈ 330 строк, 9 файлов из 800 и 25; рисковых путей 2 по исключению. Выше 780 — стоп, `escalation.md`.

## Risks

- **Телефонные B13–B19 ждут R:** детская сессия `supervised` открывается только исключением родителя (R), а сессии
  консоли ящик по построению не пишет.
- **Формат листинга `devicectl` для вложенных каталогов и `copy to --remove-existing-content`** известны только
  исполнением: разбор защитный, проверка — первая выгрузка и первое стирание на телефоне.
- **Класс защиты и чтение пометки** на телефоне не видны ни сборке, ни тестам — рисковый путь `App/Sources/BlackBox/`.
- **Параллельные правки `VoiceLoop.swift` и консоли** — R child-lock; слияние main без перезаписи истории (L35),
  правки в них минимальные.
