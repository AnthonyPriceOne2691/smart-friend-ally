>    твоей подписи касанием детский экран не открывается (подпись на до 7 дней на каждую сборку) — это защита, чтобы

## Problem

Приложение открывается консолью взрослого, а детский экран — только по подписанному исключению родителя на 7 дней,
с надписью «при родителе · до …». Родитель решил: приложение детское, оно открывается сразу на Элли; замок и надпись
не нужны, потому что телефон всегда у него и закрыт его Face ID и паролем. Прогрев модели должен идти до Элли, на
красивом экране загрузки, чтобы она могла говорить сразу, как появилась.

## Users / stakeholders

- **Дочь.** Видит загрузку, потом Элли. Касание Элли — разговор; кнопок и надписей у неё не прибавляется.
- **Родитель.** Не подписывает исключений. Чёрный ящик пишет детские сессии — он снимает их через Mac. Знак стопа в
  углу ведёт его в консоль, как сейчас.

## In scope

1. **Запуск: загрузка → Элли.** Первый экран — загрузка в облике v3: розовое небо, стекло, живая «штучка» и слово
   «Загрузка». Пока он на экране, прогревается всё для первого ответа:
   - модель с префиксом персоны;
   - голос — одна фраза синтезом без звука, с расстановщиком ударений;
   - слух: распознавание, Silero и GigaAM по реестру слуха;
   - энциклопедия и звук.
   Готово — сразу детский экран с Элли. Не готово (нет модели, голоса, микрофона, ошибка прогрева) — консоль с причиной.
2. **Замок снят.** Детский экран открыт всегда: ни исключения, ни срока, ни подписи. Надписи «при родителе» нет. «Дочке,
   при мне» в консоли возвращает Элли всегда.
3. **Знак стопа** — как сейчас: Элли замолкает сразу, без фразы, экран — консоль; Face ID нет (родитель: «пока не
   делаем»).
4. **Чёрный ящик пишет:** детская сессия — `supervised`. Приёмка без присмотра R2 (`ReleaseGate`, файл приёмки в бандле)
   не меняется: с подписанной приёмкой сессия — `child`, как задумано на будущее.
5. **Длительность загрузки** меряется от старта прогрева до решения «Элли / консоль» и печатается строкой консоли и в
   журнал. Правило экрана 14 «заставки ≤ 3 с» — про декоративные заставки, а здесь настоящая загрузка по слову
   родителя. Слово «Загрузка» — тоже его слово (правило 1 «ребёнку ни одной надписи» его не запрещает: надпись — для
   взрослого, дочь не читает).
6. **Знание:** Policy `product/child-mode` — переписана со словами родителя; `look-and-feel` (метка, правила 1, 13, 14),
   runbook `voice-loop`, `ops/black-box`, `ops/test-session`, `engineering/session`, `engineering/safety-below-model`,
   `product/session-limit`, `references/repo-map`, индексы, `log.md`. `scripts/child_mode.sh` — решение в `decisions.md`.

## Out of scope

- Face ID, экран настроек, смена облика, фонов и музыки — «пока не делаем».
- Приёмка без присмотра R2: пороги и файл — без изменений.
- Детский экран, его жесты и знак стопа — без изменений; консоль — без изменений, кроме доступности «Дочке, при мне».
- Запуск на Mac (симулятор, «My Mac») — поставка `sim-app`.

## Acceptance (observable)

- Запуск: загрузка, затем Элли без надписи — или консоль с причиной.
- Без исключения в контейнере детский экран открыт; детская сессия пишется `supervised`.
- Знак стопа — консоль; «Дочке, при мне» — снова Элли.
- Строка консоли с длительностью загрузки.

## Non-functional

- Детский экран не меняется: правила 1–3, 13, 15; `child_screen_text` и `child_screen_gestures` без новых исключений
  (экран загрузки — в `App/Sources`, его слово — по слову родителя).
- Правило 10: движение загрузки плавное, без вспышек; при Reduce Motion — без покачивания.
- Чистые решения (какой экран после прогрева, кто слушатель детской сессии, строка длительности) — в `AllyCore`, тесты
  на Linux, покрытие ≥ 70%.
- Прогрев — прежний путь загрузки модели, голоса и слуха плюс одна фраза синтезом без звука; поверхность модели
  (персона, реестр, пакет модели) не меняется.
- Предохранитель §3.4 — в `plan.md`.
