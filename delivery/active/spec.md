# Spec: пороги приёмки без присмотра и файл приёмки (R2 `release-gate`)

> **Подписано** родителем 2026-10-22 «Подписываю (Рекомендую)»: таблица «Пороги R2» спеки D2.2 + R и ответ на вопрос 9
> (`delivery/archive/2026-10-22-app-session/spec.md`, `decisions.md`). Числа порогов — оттуда дословно; примеры G12–G18 —
> те же числа на своих границах («на пороге — открыт, на шаг хуже — закрыт»), новых чисел нет. Замок R
> (`delivery/archive/2026-10-23-child-lock/`) — основа: R2 добавляет к нему путь без присмотра.

## Problem

Без присмотра замок R закрыт по построению: пути к режиму без присмотра в коде нет. Когда цели безопасности 18.10 будут
достигнуты, режим без присмотра должен открывать только подписанный родителем файл приёмки с измеренными числами на
этой сборке, а пороги — цели родителя — должны стоять в коде, а не в файле, который судят (файл пишет та же рука, что
мерит). Сейчас цели не достигнуты: справочный прогон 22.10 — 305 из 360 безопасных и 12 из 90 безобидных с заготовкой.

## In scope

1. **Пороги в коде** — таблица ниже: 9 чисел целей 1–5, 7, 8 и «детали» из цели 6 с размерами замороженных наборов.
2. **Файл приёмки** `release-gate.json` в бандле: поверхность сборки (как у исключения R) и результаты `{"ok"|"bad", "of"}`
   по целям; подпись родителя `release-gate.json.sig` — `ssh-keygen -Y sign -n ally-release` (другое пространство, чем у
   исключения: подпись исключения приёмкой не станет). Проверяет телефон тем же `SSHSignature`.
3. **Замок:** `ChildAccess.child` — без присмотра и без срока, когда приёмка верна; иначе — исключение R, как прежде.
   Причины отказа приёмки — по порядку: ключ → файл → читается → подпись → поверхность → цели по номеру (все
   несработавшие); у цели 2 обе части судятся отдельно (L48).
4. **Консоль:** строки R не меняются (G1); строка «приёмка: …» — причина или «цели безопасности приняты»; при `child`
   — «без присмотра: открыт — цели безопасности приняты».
5. **Приложение:** «Дочке, при мне» открыта и при `child`; детский экран без метки срока (`until: nil`); сессия без
   присмотра — `Audience.child`, чёрный ящик её не пишет (только `supervised`).

## Out of scope

- Файла приёмки в R2 нет: его даст прогон приёмки на одной замороженной поверхности, когда цели будут достигнуты, — и
  подпись родителя. Ключ родителя в `.github/allowed_signers` кладёт D3.2. Телефонная проверка — общая сессия теста.

## Non-functional

- Без сети, без новых зависимостей; AllyCore — Linux; подпись — CryptoKit на Mac и телефоне (как в R).
- Пороги — константы кода рядом с размерами наборов; в файле приёмки порогов нет.
- Форма: файл ≤ 500 строк, функция ≤ 50, сложность ≤ 8. Предохранитель: 800 строк, 25 файлов.

## Risks

- Первый настоящий файл приёмки — по замеру всех девяти целей на одной замороженной поверхности; иначе он судит разные
  сборки (класс L47). Хэши в файле — короткие строки с префиксом не пройдут: настоящие — длинные, detect-secrets (L38)
  судит их при коммите файла, не в R2.
- Детский экран без присмотра на телефоне — общая сессия теста (решение родителя 2026-10-23).
