## Problem

Приложение собирается только для телефона: каждая правка — установка по кабелю или Wi-Fi, а разговор дочки — с
телефоном в руках. На Mac есть всё, что нужно приложению: диктовка ru-RU (проба macOS 27.2 сегодня: finalize 0,03 с),
Metal M5, эхоподавление macOS. Но приложение для iPhone на Mac запускает только Xcode, и файлы модели, голоса и
ударений (5,50 ГБ) в его контейнер скрипт положить не может: оболочке агентов macOS не даёт доступа к данным других
приложений (TCC `SystemPolicyAppDataDetailed` — отказ по политике службы, окна нет).

## Users / stakeholders

- **Родитель.** Запускает Элли на Mac кнопкой ⌘R в Xcode, один раз отдаёт ей папку с файлами, разговаривает в консоли;
  дочь говорит при нём через микрофон Mac.
- **Дочь.** Тот же голос, слух и модель, что будут на телефоне; данные её разговоров — в контейнере приложения на Mac,
  агентам недоступны.
- **Агенты.** Готовят папку файлов и сборку, снимают первый ход по системному журналу, контейнер не читают.

## In scope

1. **Папка файлов — скрипт `scripts/mac_files.py`.** Складывает в `~/models/ally-mac` раскладку контейнера: `Models/`
   (веса E4B, Silero), `Voice/` (26 файлов голоса и ударений, словари `.gz` распакованы), `manifest.json` (путь, байты,
   sha256). Сверка до первой записи: веса — по пину `delivery/model_surface.txt`, Silero — по байтам `hearing.json`,
   голос — по `voice.json` (проверка `copy_voice.py`). Клоны APFS — место не тратится. В контейнер приложения не пишет
   никогда; повтор пропускает неизменённое.
2. **Кнопка «Файлы с Mac…» в консоли.** Только при `isiOSAppOnMac` и спящей Элли. Системное окно выбора папки →
   приложение сверяет список с реестрами бандла (`model.json`, `hearing.json`, `voice.json`): чужой путь или не тот
   размер — отказ целиком, ничего не скопировано. Каждый файл — копия рядом под временным именем, сверка байтов и
   sha256 копии, замена; несошедшийся — старый остаётся. Потом прогрев.
3. **Строка следа хода в системный журнал.** Приёмник `TraceSink` пишет ту же строку, что `Caches/turns.jsonl`
   (этапы, времена, решения маршрутизатора, версии), в os_log `com.anthonypriceone.ally` / `turn`; слова отбрасываются
   конструкцией приёмника (K9). Агент снимает первый ход командой `log show`, контейнер не читая.
4. **Metal или CPU.** Строка консоли и версия `metal` следа: устройство Metal, которое видит приложение, —
   «модель: Metal — Apple M5» или «модель: CPU — нет Metal».
5. **Запуск — `scripts/mac_app.sh`.** Генерирует проект и открывает его в Xcode; дальше родитель выбирает «My Mac
   (Designed for iPhone)» и жмёт ⌘R. Подпись — автоматическая Xcode, профиль на 7 дней обновляет тот же ⌘R.
6. **Знание.** Решение «Mac, а не симулятор» с замерами зонда; runbook `voice-loop` — раздел «Элли на Mac»; `log.md`.

## Out of scope

- Симулятор: диктовки нет, Metal слабый — решение родителя; зонд остаётся в `local/`.
- Своя сборка llama.cpp под симулятор — не нужна: на Mac идёт официальный слайс `ios-arm64` b10809.
- Запуск в обход Xcode (обёртка, `open`, прямой запуск): Gatekeeper убивает процесс и показывает окно родителю.
- Замок «при родителе» на Mac — снят родителем, детский экран — поставка `child-open`.
- Чёрный ящик с Mac — снимает родитель (поставка black-box).
- Установка на телефон, телефонные проверки — сессия теста; `reinstall_app.sh` не меняется.
- Нативное приложение macOS и Mac Catalyst.

## Acceptance (observable)

- Скрипт на этом Mac складывает 28 файлов (5,50 ГБ) и `manifest.json`, повтор — «без изменений»; не тот источник —
  стоп без записи; smoke S9 гоняет то же на временном наборе в каждом PR.
- Тесты `AllyCore` (Linux CI и Mac): план копии, отказы, копия с заменой и сохранением старого, видимость кнопки,
  строка журнала без слов; мутации красные.
- Первый ход на Mac — синтетика `say` из колонок, этапы и Metal — по `log show`; консоль родитель видит на экране.
- Сборка для телефона без подписи и оракул артефакта — как прежде; пакет модели и `reinstall_app.sh` не тронуты.

## Non-functional

- **Данные дочки.** Скрипт не пишет в `~/Library/Containers` (N3) и не читает контейнер; импорт пишет только пути
  реестров (`Models/`, `Voice/`), в `Memory/`, `Caches/`, `Ally/` — никогда (N5, N6); журнал — без слов (N8).
  Снимков экрана Mac нет; консоль видит родитель.
- **Сети нет:** правило SwiftLint `no_network` и оракул артефакта; скрипт ничего не скачивает.
- Ядро — Foundation и `AllyCore`, Linux CI, покрытие ≥ 70%; файл ≤ 500, функция ≤ 50, сложность ≤ 8; ратчет SwiftLint
  без роста.
- **Предохранитель §3.4:** план ≈ 600 строк в счёте breaker'а (код ≈ 330, тесты ≈ 270; smoke S9 в `delivery/` не
  считается), с поправкой L34/L52 +25% ≈ 750; выше 780 — стоп и разрез.

## Risks

- **Клон при копии в контейнер.** Если копия из выбранной папки не клонируется, 5,50 ГБ лягут второй раз (на диске
  свободно ≈ 99 ГБ) и копия займёт десятки секунд — замер в N9.
- **Эхоподавление на колонках MacBook.** Голос Элли из колонок может давать ложное перебивание — N9 на синтетике.
- **Диктовка в приложении для iPhone на Mac** может вести себя не как в пробе macOS — N9.
- **Параллельная `child-open`** меняет прогрев при запуске и экран загрузки; кнопка и её прогрев сливаются через
  свежий main: кто смержен вторым, тот сливает.
