## Перенесено (не эта серия)

- Формула `bm25` на Swift — только если FTS5 не окажется в системном SQLite iPhone (P23, вопрос ведущему В2).
- Векторный поиск — по промахам из чёрного ящика больше 10%. Шумовая модель распознавания для энциклопедии, алиасы
  Викиданных, doc2query — там же.
- Тема маршрутизатора для деликатного (смерть, откуда дети, война) — по данным чёрного ящика.
- Экран «Источники и лицензии» (Snowball BSD-3, база — свой текст) — с платной версией или D8 `parent-zone`.
- Рост базы сверх 300 — партиями из пробелов чёрного ящика, каждая маленькой поставкой с тем же процессом (вопрос 8).
