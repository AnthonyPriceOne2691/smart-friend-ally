## Mini-spec

Последний пункт примера Z10 подписанной спеки V2 `voice-text` (архив `delivery/archive/2026-10-23-voice-text/spec.md`,
спека серии — коммит 68202f0): строки проверенной таблицы второго круга — данными в `speech-text.json`, у каждой строки
свой тест. Источник — стенд `local/spike/voice-samples-2` (`results/ortho_table.json`, `scripts/ortho.py`, вне git):
фонемная модель, 8 озвучек на слово, «без замены → с заменой»; список строк передал ведущий 2026-10-23.

| Строка | Куда | Замер стенда | Тест |

Две строки меняют значения подписанного Z10: «его́» → «ево́» стало «йиво́», исключение «до́рого» стало «до́рога» («г»
остаётся, меняется конечный звук). Основание — замер второго круга и слово ведущего 2026-10-23 («последний пункт Z10,
новой подписи не нужно»); записано в `decisions.md`.

Уроки по путям (`Packages/AllySpeechText/`, `knowledge/engineering/speech-text.md`): **L92** — порядок «ударения по
исходному написанию, переписывание после» сохраняется, «ле́том» чинится поверх ответа расстановщика; **L28** — исключения
видят только виденное, список расширен строками второго круга, остальное — данными; **L93, L94** — конфиги и записи
адаптации не меняются. **L26, L43** — у каждого утверждения id примера, сверка дайджеста до пуша.
