## Что уже пробовал

- **Сверил, куда ушли строки:**
  - `pitch.c` — 214 вместо 170. Метод целиком: кандидаты с ценой октавы, глухой кандидат, путь Витерби с обратным ходом,
    геометрия кадров, края сигнала. Это и есть то, что убрало дребезг.
  - `psola.c` — 228 вместо 150: метки и наложение стенда, передискретизация, Баттерворт вперёд-назад, отказ памяти.
  - Swift-обёртка — 94 вместо 60: полосы, ошибки, `PitchTrack` для Z31.
  - Тесты с помощниками — 189 вместо 175: F0 и спектр меряет своя автокорреляция и Гёрцель теста, а не трекер пакета.
- **Уплотнение:** убрать API только для тестов (`PitchTrack`, `equalize` — тесты зовут C напрямую) и ужать помощников.
  Получается ≈ 790 — всё ещё выше 780. Ужимать комментарии и формат ради числа не стал: это подгонка метрики, а не
  разбиение (§9.1a).

  verify-report, сдача в том же PR.

  цепочка, которую судит Z30, едет целиком.

**Вариант B: разрезать — эквалайзер в V4b**
- Что делаем:

  Это правка подписанной спеки, её показываем родителю снова.
- Цена: ≈ 1 час, Z30 дважды. V4b растёт на ≈ 110 строк — тот же вопрос может вернуться там.

через C.
