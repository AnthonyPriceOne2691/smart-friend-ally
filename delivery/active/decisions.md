# Decisions

- 2026-10-23 · выбрал примеры G12–G18 из подписанной таблицы порогов («на пороге — открыт, на шаг хуже — закрыт») вместо новой подписи родителя, потому что все девять чисел подписаны 2026-10-22 (вопрос 9), а примеры новых чисел не вводят; решение родителя 2026-10-23 — «сейчас собираем»
- 2026-10-23 · выбрал результаты счётом с размером набора (`ok`/`bad` и `of`) вместо долей, потому что подписанная таблица закрепляет набор рядом с порогом — «19 из 20» не пройдёт за 95%
- 2026-10-23 · выбрал пространство подписи `ally-release` вместо `ally-child-mode`, потому что подпись исключения на 7 дней иначе открыла бы режим без присмотра без срока
- 2026-10-23 · выбрал `Audience.child` для сессии без присмотра вместо `supervised`, потому что чёрный ящик пишет только `supervised` (решение ведущего: только при родителе) — сессия без родителя не должна выглядеть как «при родителе»
- 2026-10-23 · выбрал «счёт вне набора — файл приёмки не читается» вместо приёма такого файла, потому что замок R закрыт при любом сомнении: «46 из 45» замером не бывает, а порог `≥` его пропустил бы (пример G15 «мусор вместо JSON», мутация убита)
- 2026-10-23 · выбрал чтение подписанного файла по назначению в ядре (`SignedFile.read(…, for: .exception | .acceptance)`) вместо пространства строкой в приложении, потому что пространство приёмки иначе не проверить тестом: G12 и G15 на Mac судят настоящие подписи OpenSSH третьим тестовым ключом, закрытый ключ удалён
- 2026-10-23 · выбрал слушателя детской сессии один раз на запуск (`child` при верной приёмке, иначе `supervised`) вместо пересоздания сессии на каждой передаче телефона, потому что приёмка лежит в бандле без срока: `child` держится весь запуск, а исключение без приёмки — всегда `supervised`
- 2026-10-23 · выбрал правку комментария `.github/allowed_signers` (формат строки с `namespaces="ally-child-mode,ally-release"`) вместо молчания, потому что `ssh-keygen -Y verify -n ally-release` на Mac откажет ключу без второго пространства; ключа в R2 нет — его кладёт D3.2 (решение ведущего)
