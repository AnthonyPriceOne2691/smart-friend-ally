Вопрос дословно: «Русская диктовка Apple в симуляторе не работает совсем (симулятор не умеет, обойти нельзя), а на самом Mac работает. К тому же видеокарта симулятора слабая — модель там пойдёт только на процессоре. Как запускать Элли на Mac для разговоров?» Варианты: «Приложение для iPhone прямо на Mac (Рекомендую)» — «Та же диктовка, что на телефоне; модель на видеокарте Mac; те же файлы, что на телефоне — что работает на Mac, то и на телефоне. От тебя: разрешить Xcode добавить этот Mac в твою бесплатную команду разработчика (если вход истёк — окно Apple ID для твоих рук), один раз нажать «Разрешить» на микрофон, раз в 7 дней — пересборка одной командой.» / «В симуляторе, слух — GigaAM» — «Слушает другой распознаватель (GigaAM-v3, в исследовании точнее диктовки, но на детской речи ещё не проверен). Модель на процессоре, отвечает медленнее. Нужна своя сборка библиотеки модели. На Mac работает уже не то, что будет на телефоне.» Ответ: «Приложение для iPhone прямо на Mac (Рекомендую)». Цена — подпись Personal Team на 7 дней и Mac в профиле команды
- 2026-10-29 · выбрал запуск кнопкой ⌘R в Xcode и кнопку «Файлы с Mac…» вместо исключения Gatekeeper и полного доступа к диску для Терминала, потому что так решил родитель 2026-10-29 (by=human:anthony, через ведущего). Замер до вопроса: обёртку `Wrapper/` и прямой запуск syspolicyd убивает («Terminating process due to Gatekeeper rejection», «Code did not match any currently allowed policy»), запуск обёртки показал родителю окно Gatekeeper; оболочке агентов (Cursor) TCC `SystemPolicyAppDataDetailed` отказывает по политике службы без окна, права «Инструменты разработчика» у неё нет. Вопрос дословно: «Mac пускает приложение для iPhone только из Xcode, а файлы (модель, голос, ударения) в его папку может положить только само приложение — агентам macOS туда доступ не даёт (это заодно закрывает от них разговоры дочки). Как запускать?» Варианты: «Кнопка ▶ в Xcode + «Файлы с Mac…» (Рекомендую)» — «Запуск: открыть Ally в Xcode, выбрать «My Mac (Designed for iPhone)», нажать ⌘R — так же ставится новая версия и обновляется подпись. Файлы: скрипт складывает их в папку (место не тратится), а в консоли на Mac появится кнопка «Файлы с Mac…» — один раз выбрать эту папку, приложение заберёт файлы само. Агенты данные дочки не видят.» / «Исключение Gatekeeper + доступ к диску» — «В Настройках → Конфиденциальность: «Всё равно открыть» для Ally и полный доступ к диску для Терминала; тогда скрипты сами запускают и кладут файлы. Цена: Терминал видит данные всех приложений, включая разговоры дочки; возможно, «Всё равно открыть» придётся нажимать после каждой пересборки.» Ответ: «Кнопка ▶ в Xcode + «Файлы с Mac…» (Рекомендую)». Цена — каждый запуск и новая версия — кнопкой родителя; агент приложение не запускает
