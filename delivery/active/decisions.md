# Decisions — D6.1 duplex-audio (серия «живой разговор»)

- 2026-10-25 · запасная Milena остаётся полудуплексом (пока звучит она, кольцо очищается, счётчик не считает) — вместо переноса её в движок (`AVSpeechSynthesizer.write` → player) — потому что это временный голос до файлов V4b2, а перенос — ≈ 30 строк ради него; эхоподавлению опора только звук общего движка
- 2026-10-25 · кольцо предзаписи отдаётся слушанию, только если в нём есть её речь, с начала речи минус 0,3 с (X19) — вместо всего кольца на каждом слушании — потому что остаток голоса Элли после эхоподавления диктовка пишет словами, а предзапись D7 уже начинается с открытия микрофона
- 2026-10-25 · порог наложения в D6.1 — порог активности реестра слуха (Silero 0,5), без своего — вместо поднятого порога на время голоса из черновика архитектуры — потому что без записей порог — догадка: X10 на телефоне покажет, нужен ли он, и реестр поднимет его без кода
- 2026-10-25 · спека и план D6.1 пишутся до мержа V4b2, код — после — вместо ожидания с документами — потому что примеры X9–X12 подписаны, а подписи родителя ведущий собирает пачкой; до кода план сверяется с player V4b2 (T1)
- 2026-10-25 · запас кольца `lead` — 0,8 с — вместо 0,3 с из спеки и плана — потому что флаг Silero поднимается через 0,20 с медиана и 0,71 с p95 после начала речи (замер D7, `turn-detector`), и с 0,3 с первый слог терялся бы у каждого двадцатого хода; X11 на флаге, поднятом на 0,4 с позже речи, — первый слог в кольце, мутация «без запаса» его краснит
- 2026-10-25 · счётчик наложений при флаге Silero считает с подъёма флага (`flagMinimum` = `vad.min_speech` 0,25 с) — вместо 250 мс флага сверху — потому что Silero поднимает флаг только после своих 0,25 с речи, и двойной порог считал бы наложением лишь ≥ 0,5 с речи вместо 250 мс решения родителя 3
- 2026-10-25 · ядро D6.1 (счётчик, кольцо, ключи реестра) делается до мержа V4b2 — вместо ожидания всей поставки — потому что оно не зависит от player голоса (слово ведущего 2026-10-25); без вызывающего ядро отдельно не сдаётся (L50): мерж — после проводки
