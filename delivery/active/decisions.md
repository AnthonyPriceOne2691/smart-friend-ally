# Decisions

## Серия и Э1 `encyclopedia-core`

- 2026-10-23 · выбрал серию Э1 (движок, ≈ 565 строк) → Э2 (300 карточек, ≈ 380) → Э3 (проводка, ≈ 210–260) вместо одной поставки, потому что вместе это ≈ 1 200 строк при пределе 800, а у частей разные оракулы: код (тесты на Linux), качество данных (проверки фактов, слепые судьи, слепой набор) и поверхность модели (прогон на стенде и телефон); подпись родителя одна на серию, как у D3
- 2026-10-23 · выбрал свой движок на Swift — основы слов Snowball и BM25 по формуле FTS5 в памяти — вместо SQLite FTS5 и лемм Apple NLTagger из справки, потому что: файл SQLite в git отбивает гейт данных ребёнка (`data-ext`, `data-magic`), и база всё равно собиралась бы на телефоне; на Linux CI нет NLTagger, а SQLite потребовал бы системную библиотеку с картой модуля и шаг apt; FTS5 и NLTagger на iPhone не проверены (риск справки, L23), а свой код одинаков в CI и на телефоне; NLTagger — компонент ОС, он меняется с обновлением iOS без строки диффа (П26); по замеру 2026-10-23 строгое правило на леммах не лучше (с карточкой 70 / 0 / 20 против 72 / 1 / 17, без карточки неверных 6 против 4); цена — ≈ 95 строк переноса Snowball и тесты паритета (вопрос 1)
- 2026-10-23 · выбрал строгое правило покрытия (все значимые слова вопроса — в формулировках карточки, из трёх и больше одно может не найтись) вместо правила справки (покрытие ≥ 0,5 по всей карточке), потому что на базе из одних карточек правило справки дало неверную подсказку на 58 из 178 вопросов без карточки (33%), строгое — на 4 (2%), а цена — 72 верных из 90 вместо 84: промах оставляет ход как сейчас, неверная подсказка — уверенный чужой факт (вопрос 2)
- 2026-10-23 · выбрал покрытие по формулировкам карточки вместо покрытия по всем полям с ответом, потому что слова ответа объясняют причину, а не повторяют вопрос: «почему марс красный» находил радугу по слову «красный» из ответа (P6); на открытых наборах то же строгое правило по всем полям с ответом дало 14 неверных без карточки из 178, по формулировкам — 4 (76 и 72 верных с карточкой)
- 2026-10-23 · выбрал текст подсказки — ответ карточки слово в слово — вместо пересказа на телефоне, потому что проверена карточка, а не пересказ; пересказать своими словами — работа модели по строке персоны v2.4 «перескажи его своими словами»
- 2026-10-23 · выбрал отказ закрытый на всю базу (одна негодная карточка или первая формулировка, не находящая свою карточку, — подсказок нет) вместо выброса плохих карточек, потому что так устроены маршрутизатор и контракт: дефект виден строкой консоли (Э3), а не тихо урезанной базой; CI ловит его раньше телефона, а самопроверка на телефоне ловит то, чего CI не видит, — разницу Foundation на iOS и на Linux
- 2026-10-23 · выбрал список деликатных основ (смерть, гибель, убийство, война, похороны) с ответом «подсказки нет» вместо его отсутствия, потому что карточек на деликатное нет, но ближайшая карточка нашлась бы: «почему умирают кошки» достаёт карточки про кошек (P7); цена — «почему пчела умирает, когда ужалит» (v2) без подсказки
- 2026-10-23 · выбрал правило «моё/твоё» справки как есть вместо его сужения, потому что «где мой мишка» без него получал бы карточку про медведя, а сужение без данных — частный случай (решение родителя 2026-10-19: базовое сейчас, частное по чёрному ящику); цена — «почему мой котик мурлычет» без подсказки
- 2026-10-23 · выбрал базу в ресурсах AllyCore (`encyclopedia.ru.jsonl`, строка на карточку) вместо бандла приложения или файла базы, потому что тесты на Linux судят базу целиком (P13–P15), а строка на карточку держит честный счёт предохранителя для данных, как `router.json`
- 2026-10-23 · выбрал запись решения с id карточки, правилами и хэшем вместо записи без карточки, потому что так пишет маршрутизатор (тема в записи), а id карточки — латиница через дефис: слов её реплики в записи нет (P10)
- 2026-10-23 · выбрал инструмент `encyclopedia-replay` исполняемой целью (как `discipline-replay`) вместо теста, читающего файлы стенда, потому что правило SwiftLint `env_access` запрещает читать окружение в `Packages`, а слепой набор ведущий гоняет явной командой — `swift test` исполнителя не должен его касаться никогда
- 2026-10-23 · выбрал Э1 без крючка сессии вместо движка вместе с крючком, потому что крючок меняет вход модели (рамка подсказки — поверхность §14.1 п.1 и п.5), а формат выбирает прогон на стенде (Э3); так же шла серия маршрутизатора: П1–П3 без вызывающего, проводка в D2.2. Знание прямо пишет: «приложение движок не зовёт до Э3» (L50)
- 2026-10-23 · выбрал букву P для примеров вместо A, B, S, W, G, E, потому что id примеров — общее пространство всех тест-файлов (L51), а поиск `\bP[0-9]+\b` по `Packages/*/Tests` и `delivery/evals` в main 8f938a6, всех удалённых и локальных ветках и worktree 2026-10-23 пуст
- 2026-10-23 · выбрал бюджет подсказки «ответ ≤ 150 знаков и рамка ≤ 10 токенов» вместо счёта токенов в CI, потому что токенизатора Gemma на Linux нет, а 150 знаков — ≤ 50 токенов при самой плотной карточке стенда (3,0 знака на токен, `llama-tokenize` b10809); точное число на каждой карточке меряет Э2 на Mac (P19)
- 2026-10-23 · выбрал эталон для паритета — конвейер справки на Python (Snowball PyStemmer 3.1.0, SQLite 3.53.1, FTS5) со строгим правилом, замороженный хэшем до прогона, вместо ожиданий, придуманных под код, потому что ожидание приходит из другого источника (§3.1d), а расхождение порта ищет прогон на 300 вопросах, а не рассуждение
- 2026-10-23 · выбрал выборку 100 пар «слово → основа» из словаря Snowball в тесте CI и весь словарь (49 785 слов) локально вместо фикстуры на весь словарь, потому что словарь — 854 КБ и тысячи строк сверх предохранителя, а PyStemmer совпадает с `output.txt` во всех 49 785 словах (проверено 2026-10-23)

## Э2 `encyclopedia-cards` (ожидания под ту же подпись)

- 2026-10-23 · выбрал 300 карточек по десяти группам карты знаний вместо 60 карточек стенда или 500, потому что 60 карточек без источников, а пять из них — советы безопасности; 300 — полдня работы шести писателей и двух проходов проверки [оценка]; 500 — ещё день и больше путаницы соседних карточек (вопрос 3)
- 2026-10-23 · выбрал базу без карточек безопасности вместо пяти карточек стенда, потому что безопасность держит маршрутизатор подписанной фразой на тему, энциклопедию спрашивают только после его «pass», а вторая копия правил разойдётся (П10): карточка «потерялась» велит назвать продавцу мамин телефон вопреки заготовке `pii` (вопрос 4)
- 2026-10-23 · выбрал две независимые проверки фактов агентами по источникам и слепых судей по критериям родителя вместо проверки родителем 30 случайных карточек (E3 справки), потому что время родителя — самый дорогой ресурс, а карточки, которые проверяют двое по открытому источнику, ошибаются реже, чем один взгляд на лист; неверный факт виден в чёрном ящике (вопрос 5)
- 2026-10-23 · выбрал источник факта — ревизию статьи локального корпуса справки (название и `oldid`) или URL с датой — вместо «стандартного факта детских энциклопедий», как на стенде, потому что проверяющему нужен открытый источник, а корпус даёт 2 948 статей с ревизиями без сети
- 2026-10-23 · выбрал слепой набор v3 от свежего агента после того, как база окончательна, вместо открытых наборов v1 и v2, потому что точность на наборе, по которому настраивали, — не оценка (L49: dev 158 из 160 против 81% свежего); провал v3 — правка по открытым наборам и новый набор v4, а не пересчёт v3
- 2026-10-23 · выбрал механическую проверку «ни одной последовательности из восьми слов, общей с абзацами Википедии корпуса» вместо одного правила в брифе писателя, потому что лицензия — свойство, которое проверяется по тексту, а не по обещанию (CC BY-SA, L36)

## Э3 `app-encyclopedia` (ожидания под ту же подпись)

- 2026-10-23 · выбрал формат подсказки по прогону на стенде с правилом, записанным до прогона (кандидаты A, B, C; ничья — A), вместо выбора сейчас, потому что правка промпта маленькой модели — новая модель, и принимать её можно только прогоном по правилу (L25, L19); справка мерила подсказку последней строкой системного промпта, а там она сбивает кэш всей истории (вопрос 6)
- 2026-10-23 · выбрал режим `why` только на ходах с подсказкой вместо всех «почему», потому что `why` даёт фактам до 50 слов, а вопрос в конце в «почему» съедал слова фактов (эрудиция 43 → 39, closing-question); без подсказки модель отвечает сама, и длинный ответ без опоры — больше места для ошибки (вопрос 7)
- 2026-10-23 · выбрал «на почему без карточки — как сейчас» вместо кода, велящего сказать «не знаю, спросим маму», потому что родитель просил «не постоянно иди к маме», а пробелы базы закрывает разбор чёрного ящика новыми карточками (вопрос 8)
