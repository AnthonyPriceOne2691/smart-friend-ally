## Approach

1. **Порядок.** Подпись родителя под V11–V18 → `eval-smoke.md` → код срезами (`tasks.md`) → verify → handoff в том же PR.
2. **`Motion` (`ShellCore`).** Класс-аниматор (состояние меняется только в `step`): веса четырёх поз сессии
   (`TalkState.Pose`) — пружины ω = 11, ζ = 1 полуявным Эйлером с подшагом ≤ 8 мс; поза кадра — сумма поз по весам
   (`Pose.mix`); фазы колебаний (парение, дыхание, хвост, жабры, счёт жабр) накапливают темп × `dt`; моргание — расписание
   прототипа (первое через 2,2 с, затем 0,2 + 2,6…5,6 с, двойное с вероятностью 0,2) на генераторе с зерном; после
   `goodbye` → `asleep` — линия прототипа `poseBye`: зевок (0,3–0,9 с нарастает, 1,6–2,4 с уходит) и сон (1,7–3,3 с).
   `step(dt, phase, voice, mic, calm) -> Frame`.
3. **`Frame`** строится из накопленных фаз вместо `sin(t · темп)`; `Frame.at(phase:time:)` Ш1 остаётся (V1–V9, снимки V8)
   как частный случай без переходов.
4. **`Pose`**: поза зевка, поле высоты рта (`mouthTall`), смесь поз, спокойный размах (×0,4 колебаний, ×0,6 темпа жабр
   и хвоста — Reduce Motion).
5. **`FrameRate`** (`ShellCore`): `Heat` (nominal, fair, serious, critical) и частота по позе: 30, 120, 30, 60; serious —
   не больше 30, critical — 15.
6. **`LiveScene`** (`ShellUI`): `TimelineView(.animation(minimumInterval:))` с частотой по позе; аниматор — в `@State`;
   нагрев — из `ProcessInfo.thermalState`, Reduce Motion — из окружения SwiftUI. `ShellScene` рисует готовый `Frame`.
7. **Полосы V18:** аниматор шагает 1/120 с по сценарию фаз, кадры в моменты примера рисует `ShellScene(frame:)`.
8. **Знание:** ADR `character-rendering` — `implementation:` дополнить `Motion.swift` и `LiveScene.swift`; `knowledge/log.md`.

## Rejected alternatives

- **Неявные анимации SwiftUI (`.animation(.spring)`) вместо своих пружин** — отклонено: они тянут каждое значение
  отдельно и не смешивают позы целиком, фаза колебаний скачет при смене темпа, а на Linux их не проверить.
- **Одна Ш2 с движением и светом** — отклонено: с поправкой +50% ≈ 900 строк при пределе 800, а исключение родитель дал
  только Ш1.
- **`CADisplayLink` в UIKit** — отклонено: второй путь кода для Mac и телефона; `TimelineView` — тот же SwiftUI, что
  рисует и снимки.
- **Моргание настоящим случаем в тестах** — отклонено: невоспроизводимо; генератор с зерном, на телефоне зерно — время.
- **`ProcessInfo.thermalState` в ядре** — отклонено: на Linux его нет; своё `Heat` в ядре, перевод — в `ShellUI`.
- **Зевок и после стопа родителя** — отклонено: стоп — тишина сразу (контракт R), зевок — только после прощания.
- **Взгляд по сторонам, хихиканье на тап, «радуется»** — отклонено: вне подписанного содержания серии («без полировки
  сверх», слово родителя 2026-10-23).
