# Plan: чёрный ящик в приложении (D3.2 `app-black-box`)

Уроки архива. **L33**: документы — первым коммитом ветки, до кода; `eval-smoke.md` — до кода. **L50, L58**: исполнитель
считается подключённым, когда живой путь даёт ему входы; ящик подключается через тот же `TraceFanOut`, который держит
пример через драйвер `Conversation` (D3), а реплику отдаёт настоящий `PhoneListener`. **L44**: длина кадра — вход
алгоритма: отсчёты берутся из преобразованного буфера, а не из тапа (100 мс на телефоне); формат — с устройства. **L23**:
формат распознавателя — проба на устройстве: строка консоли и стоп, если не Int16 моно. **L46**: снимков экрана телефона
нет — строки консоли видит родитель, а состояние ящика пишется в журнал `os.Logger` без слов. **L15**: первый запуск
новой подписи — доверие сертификату на телефоне, шаг владельца. **L45**: числа из JSON — как Double, явно (команда на Mac
читает `bytes`). **L60**: `AudioIO.listen` не отменяем и не отдаёт начало речи — пауза до её речи ждёт поставки слуха
или D6, `App/Sources/Audio/` не трогаем. **L56, L57**: её звук — WAV бит в бит; каждый текстовый файл ящика и его
производные — с заголовком; выгрузка кладёт файлы как есть, без производных. **L35, L14**: перед ссылкой на CI —
`mergeable`; после слияния main — строгий `delivery_check`. **L43**: сверка дайджеста — до пуша сдачи. **L59**: мутации
называть по механизму. **L61**: поставка-проводка — бюджет по плану без поправки. Не применимы: **L1, L12** — ролей «до
кода» не осталось; **L2** — нового манифеста нет; **L36** — зависимостей нет. Уроки сдачи — L83, L84, L85.

## Approach

1. **Порядок.** Документы → `eval-smoke.md` → код срезами → сборка для устройства и оракул артефакта на Mac → verify
   → PR и CI. Телефонные B13–B19 — после мержа R при родителе; подпись поверхности стирания — палец родителя.
2. **`PhoneDisk`** (`App/Sources/BlackBox/`). Корень `Application Support/BlackBox`: создаётся с
   `FileProtectionType.complete`, класс ставится и существующему каталогу; `isExcludedFromBackup` ставится и читается
   обратно со свежего URL (кэш значений сброшен); `isPrivate` — пометка и класс прочитаны. `write` — каталог сессии с тем
   же классом, файл `Data.write(options: [.atomic, .completeFileProtection])`; `files()` — обход корня с размерами;
   `remove` — `removeItem`.
3. **Крючок у распознавателя** (`App/Sources/Speech/DictationRecognizer.swift`). `Phrase` получает `onFed`: после
   `convert` и `input.yield` — отсчёты того же буфера, если формат Int16 моно; счёт отданного — в `fed`. `prepare()`
   дописывает в строку готовности формат: «16000 Гц, Int16, моно»; иначе — «её звук не пишется: формат …».
4. **Реплика ящику** (`PhoneListener`). Открытие микрофона — время до `audio.listen`; конец речи и закрытие — из
   результата `listen` (последний голосовой кадр и решение о конце); текст известен — после `phrase.finish()`. Тишина —
   реплики нет. `Utterance` уходит ящику через замыкание до возврата текста; журнал — «слух: распознавателю отдано N
   отсчётов».
5. **Проводка и консоль** (`VoiceLoop`, `AllyApp`). `BlackBox(disk: PhoneDisk())`; сток сессии —
   `TraceFanOut([TraceFile, box])`. Строка ящика `screen.box` обновляется на каждой смене состояния сессии и пишется в
   журнал при изменении. Кнопка «Стереть чёрный ящик» — только когда Элли спит; подтверждение «Стереть N сессий (M МБ)?»
   с текстом «Сначала выгрузи на Mac.» (N и М — `held()`), действие — `eraseAll()`.
6. **Ядро** (`BlackBox.held()`): сессии и байты на диске; `eraseAll` берёт тот же подсчёт папок (П10). Тест `// B17`.
7. **Команда на Mac** (`scripts/blackbox.py`), черновик написан параллельным агентом и проверен здесь: `pull` — сторожа
   (`git check-ignore`, iCloud), телефон на связи, листинг `devicectl … info files --json-output`, копирование новых
   сессий во временную папку, сверка заголовка, байт и FNV-1a, перенос сверенного в `local/blackbox/<дата>/<сессия>/`;
   `erase` — `pull`, затем `devicectl … copy to --remove-existing-content true` пустой папкой только для сверенных.
   Смоук S7 `delivery/evals/smoke/blackbox_pull.sh` — семь случаев на двойнике `xcrun`.
8. **Знание.** `ops/black-box`, `engineering/voice-loop` (команды выгрузки и стирания), `ops/child-data`; `knowledge/log.md`.

## Rejected alternatives

- **Второй конвертер в `VoiceLoop` вместо крючка в `Phrase.feed`** — отклонено: буфер был бы равен распознавательному
  только по замеру, а не по построению; родитель выбрал крючок с исключением (ответ 8).
- **Начало речи — правкой `AudioIO`** — отклонено: третий рисковый путь (`App/Sources/Audio/`) сверх исключения.
- **Стирание с Mac через `devicectl uninstall`** — отклонено: стирает и веса (≈ 5 ГБ, 3,5 мин копирования), и след.
- **Стирание через приложение по аргументу запуска** — отклонено: запуск с аргументом — тот же агентский доступ, а
  приложение не знает, что выгружено; сверку держит Mac.
- **Своя строка «● запись» на детском экране** — отклонено: экран — R и оболочка; ящик отдаёт строку консоли и журнал.

## Risks

- Телефонные примеры ждут R и родителя; без них сдача (`handoff`) не пройдёт: рисковые пути без исполнения — отказ
  гейта (§12.6). До исполнения — verify с PR и CI.
- Формат листинга `devicectl` для вложенных каталогов и поведение `--remove-existing-content` — первое исполнение на
  телефоне; разбор защитный, неизвестный формат — внятная ошибка.
- `VoiceLoop.swift` и консоль правит R — конфликт при слиянии решается сложением, правки минимальные.

## Rollout

`manual-deploy`: переустановка поверх `bash scripts/reinstall_app.sh <UDID>` — решение родителя. Мерж — ведущий.

## Test / eval strategy

- `// B17` — `BlackBoxTests` (`held()`, стирание, строка); B15, B16 — смоук S7 (`# B15`, `# B16`); B13–B19 — исполнение
  на телефоне в verify-report «Исполнение рисковых путей». Сборка `.app` для устройства и оракул артефакта — на Mac.
