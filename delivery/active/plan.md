# Plan: маршрутизатор до модели — люди, тайны, «потерялась» и правила содержания

Уроки архива: **L8** — у каждой статьи проба-нарушитель и хитрая чистая с обеих сторон; каждая статья и каждый выход,
выключенные, краснят пробу. **L14** — строгий `delivery_check --require-ci --diff-base origin/main` гоняется сразу
после коммита документов и после каждого слияния main, а не в конце. **L19** — эталон замораживается: хэш
`router_core.py` П1 записан (`19302afd…`), новая редакция — новым хэшем в `decisions.md`, правка после паритета — новым
прогоном. **L25** — правило принимается полным прогоном: паритет и числа на всём корпусе 787 строк × 2 режима флага,
а не на пробах. **L26** — ноль у прибора на Swift — повод для пробы: абляция статей и правил содержания, дайджест
утверждений по `// R<n>` на строке функции. **L27** — паритет по корпусу находит дефекты эталона; правка — в эталоне и
в Swift сразу. **L28** — список видит только виденное: двойники считает генератор по всему частотному списку, хэш
держит свежесть; правило меряется формой (статья условий), а не дописанным словом. **L29** — две цели могут разойтись:
указатель страха (R13) и вопрос в конце (`closing_question`) меряются вместе — указатель вытесняет вопрос, а не
наоборот. **L30** — парное судейство не нужно: скрытый набор не прогоняется. **L33** — первый коммит поставки — только
документы. **L34** — бюджет движка считается по Swift прошлых поставок: интерпретатор статей и правила содержания
посчитаны по набросанному Swift, а не по строкам эталона; перенос темы спасает 1–2% бюджета, поэтому темы не режутся
ради запаса. **L35** — перед записью ссылки на прогон в verify-report проверить `mergeable`; конфликт с main
(параллельная поставка голосового ядра трогает `CLAUDE.md`, `INDEX.md`, `knowledge/log.md`) — слить main без
перезаписи истории. **L9/L10** (`CLAUDE.md`) — синхронизация по содержимому: «сейчас» = «станет», наката нет; условие
шага — код возврата гейта, а не вывод фильтра. **L36/L37** (`CLAUDE.md`) — не применимы: новых лицензий и утверждений
вендора поставка не вносит (частотный список — тот же, CC BY-SA 4.0).

## Approach

1. **Эталон.** `router_core.py` (стенд вне git) получает темы-статьи: разбор условия `condition`, контекстные
   предикаты, `clauses` (первая выполненная статья, выход темы), флаг `forget`. Копия П1 — `router_core.p1.py`.
   Решения П1 на 787 строках × 2 режима не меняются (проверено на черновике: 0 расхождений).
2. **Данные `router.json`:** 29 новых понятий (строка на понятие), 8 наборов, 10 тем (строка на тему), двойники
   (`make_router.py exact`), пробы самопроверки новых тем (строка на пробу, с темой).
3. **Swift маршрутизатора:** новый файл `Clause.swift` — условие, статья, позиции атомов, предикаты, решение темы;
   `RouterData.Hazard` — поля статей; `Router.route` — флаг `forget` в `Routed`; `Scene.outcome` — тема без предмета
   идёт в статьи.
4. **Swift контракта:** новый файл `Content.swift` — `extract_pii` по её реплике, `human_claim`, `pii_echo`,
   `pii_request`, `secret_promise`; `TurnPass.violation` — таблица правил в порядке эталона; `TurnContract` —
   `heard`, `decision`, указатель темы и запасная фраза; `contract.json` — регулярки, девять текстов, указатели.
5. **Тесты** (метки `// R<n>` и id примеров на строке функции): примеры спеки; пробы с обеих сторон по темам; абляция
   статей и выходов; fail-closed на новых темах; журнал; флаг игры и указатель; правила содержания по фикстуре проб
   эталона; паритет контракта на сохранённых ответах с новыми правилами; заготовки через контракт.
6. **Замер:** `discipline-replay router` (release) на 787 строках × 2 режима — паритет и p95; числа открытых наборов
   (R1 по семи ситуациям быта с `judge_safety`, R3).
7. **Знания:** `safety-below-model` — реестр и раздел маршрутизатора; `knowledge/log.md`.

## Stack / boundaries

- Swift 6.4, только Foundation; CI на Linux (джоба `swift`). Приложение и вызов модели — не здесь. Стенд — `local/`
  вне git; скрытый и свежий наборы не открываются и не прогоняются.

## Risks

- **Предохранитель.** План впритык к 700; рост сверх 800 — сначала фикстуры и пробы, затем перенос последних тем
  (`fear`, `alive`) в П3 записью в `decisions.md` и `escalation.md`; исключение не пишется.
- **Скорость (R12).** Понятий 51 вместо 23: эталон на Python медленнее в 2,1 раза (p95 8,1 → 17,3 мс); Swift П1 —
  2,17 мс, прогноз ≈ 4,6 мс при пределе 5. Не уложится — отсечение по длине в `Lexicon.reaches` до динамики.
- **Регулярки и Unicode Swift против Python** в правилах содержания (`\b`, `\w`, `(?<!не )`): через `Contract.compile`
  (семантика Python); паритет на пробах эталона и на 110 сохранённых ответах.
- **Ложные заготовки на безобидном:** «тётя Света подарила мне куклу» (dev10) → «чужой даёт» — без списка имён
  знакомого взрослого не отличить; принято (базовые случаи), запись в verify-report.
- **Подгонка под dev:** статьи — упрощённые грамматики router3 (базовые случаи), без правил под одну строку.

## Rejected alternatives

- **Функция на тему, как в router3** — отклонено, потому что перенос ≈ 270 строк Python в Swift и эталон двумя
  копиями логики съедает бюджет поставки, а правка по данным чёрного ящика была бы правкой кода, а не данных.
- **Список имён router3 в данных** (чтобы «тётя Света» не считалась чужой) — отклонено, потому что список личных имён
  в git может совпасть с настоящими именами детей.
- **Отдельный режим безопасности хода целиком (R13 серии)** — отклонено упрощением родителя: только указатель.
- **Порт `honesty` эталона** — отклонено, потому что «ты живая?» решает маршрутизатор до модели.
