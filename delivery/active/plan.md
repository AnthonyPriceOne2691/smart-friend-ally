## Approach

1. `Speculation.swift` (AllyCore): обёртка `LanguageModel`. `start(текст)` — новый ответ модели, задача копит последний
   снимок; `drop()` — спекуляция брошена (продолжение, тишина, другой текст, стоп): `model.cancel()`, счёт `spec_cancels`,
   дописанный до броска ответ — `spec_stale`; `reply(to:)` с теми же буквами — отдаёт накопленное и живой поток
   (`spec_reused`, `spec_lead`), иначе бросает начатое и зовёт модель заново; `cancel()` — отмена хода, без счёта;
   `takeStages()` — этапы для записи.
2. `Session.swift`: `plan(текст)` — решение маршрутизатора, её прощание, скрипт — одна функция для хода и спекуляции;
   события `.tentative`, `.resumed`; ход зовёт модель через `Speculation`; запись получает этапы спекуляции.
3. `Conversation.swift`: `Listener.listen(_:events:)`, поток событий с одним потребителем, допивается до `.heard`.
4. `TurnDetector.swift`: `TurnEnding` отдаёт «возможно, конец» и «продолжение» слуху.
5. App: `Phrase.tentative()` — `finalize(through: nil)` и собранный текст (`App/Sources/Speech/`); `PhoneListener` —
   события детектора по порядку: на «возможно, конец» — текст диктовки, на «продолжение» — событие.
6. Знание: `turn-detector.md`, `session.md`, `safety-below-model.md`, `voice-loop.md`, `knowledge/log.md`.

## Rejected alternatives

- Удержание голоса внутри хода сессии — состояния и записи хода стали бы черновыми; обёртка модели оставляет сессию
  прежней (решение серии).
- Откат дописанного ответа из KV — правка `Packages/AllyLlama`, второй рисковый путь; место — D5 (ответ 5 родителя).
- Текст на «возможно, конец» из промежуточных результатов диктовки — их свежесть не гарантирована; `finalize(through:)`
  даёт итог за 0,02 с (проба).
