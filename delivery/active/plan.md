## Approach — `memory-core`

1. **Порядок.** Подпись родителя под спекой, планом и ответами 1–9 → `eval-smoke.md` (M15–M25) до кода → implement
   срезами (`tasks.md`) → verify → handoff. `AllyCore`, `AllyDiscipline`, `AllyLlama` и `App/` не трогаем.
2. **Пакет (`Packages/AllyMemory/Package.swift`).** Цели: системная библиотека `CSQLite` (`module.modulemap`: `header
   "shim.h"`, `link "sqlite3"`; `shim.h`: `#include <sqlite3.h>`; провайдер `apt: libsqlite3-dev`), `Memory` (ресурсы
   `process("Resources")`), `MemoryTests`. Платформы — iOS 17, macOS 14, как у соседей.
3. **SQLite (`SQLite.swift`).** Тонкая обёртка без внешних библиотек: соединение (`sqlite3_open_v2` с флагами от
   вызывающего — на телефоне `memory-app` добавит класс защиты), `exec`, подготовленный запрос с привязкой текста, целого,
   вещественного и NULL, чтение строк, транзакция `BEGIN IMMEDIATE … COMMIT` с откатом при ошибке, закрытие; ошибка несёт
   код и текст SQLite. `SQLITE_TRANSIENT` — `unsafeBitCast(-1, to: sqlite3_destructor_type.self)`. Регистрацию своей
   функции добавит `memory-extract` (триггер запрета).
4. **Схема (`Schema.swift`).** `meta(key, value)` — версия схемы 1, эпоха стирания; `entity(id, kind CHECK child|person|pet|
   creation, relation CHECK mom|dad|brother|sister|grandma|grandpa|NULL, first_seen REAL)`; `fact(id, entity_id → entity ON
   DELETE CASCADE, trait CHECK name|age|birthday|species|color|favorite|likes|can|detail, slot CHECK color|food|animal|game|
   toy|cartoon|song|book|other|NULL, value TEXT, value_key TEXT, session TEXT, turn INTEGER, confidence REAL CHECK 0…1,
   first_seen REAL, last_seen REAL, sessions INTEGER, status CHECK active|superseded, superseded_by → fact)`; возраст —
   CHECK 1…20. Коды — латиницей: подписи по-русски живут в ресурсе (П10, `inline_prompt`). `PRAGMA journal_mode = WAL`,
   `secure_delete = ON`, `foreign_keys = ON` — с чтением обратно.
5. **Типы (`Facts.swift`).** `Subject` (она; близкий — отношение и имя; питомец — вид и кличка; придуманное — что и имя),
   `Trait`, `Slot`, `Anchor` (`said` 0,9, `found` 0,8, `agreed` 0,6 — уверенность только из таблицы кода), `Candidate`
   (о ком, признак, слот, значение, ход, опора — поля уверенности нет), `MemorySession` (id, начало, кандидаты), `Fact`,
   `WriteReport` (добавлено, подтверждено, заменено, пропущено как более старое, отклонено целиком).
6. **Хранилище (`MemoryStore.swift`).** `open(at: каталог)` — создаёт `memory.sqlite`, схему, прагмы. `write(_ session)` —
   одна транзакция: сессия старше эпохи стирания — отказ целиком; личность сущности — правила спеки, `value_key` —
   нижний регистр, «ё» → «е», пробелы схлопнуты; однозначный признак: тот же ключ → подтверждение (уверенность — большее
   из прежней и новой опоры + 0,05, не выше 1,0; сессий +1; последнее появление — позднее, первое — раннее, написание —
   самой ранней сессии), другой ключ из сессии не старше активного значения → новый активный факт, прежний — `superseded`
   со ссылкой, из более старой — пропуск; многозначный: тот же ключ → подтверждение, иначе новый. `eraseAll(now:)` —
   закрыть, удалить `memory.sqlite`, `-wal`, `-shm`, `-journal`, открыть заново, записать эпоху; ответ — сколько стёрто.
   `status(now:timeZone:)` — `empty`, `knows(n)`, `erased(at)` и строка консоли из ресурса (числительное — «факт / факта
   / фактов»). `facts()` — активные факты с сущностями для блока.
7. **Блок (`MemoryBlock.swift`).** Чистая функция `render(facts, counter, budget)` → текст и вырезанное: строки и порядок
   спеки, потолки строк из ресурса (остаются последние подтверждённые), порядок внутри строки — первое появление, ход,
   значение; бюджет — по рангу из спеки, при равном ранге — давнее подтверждённое, ядро не вырезается; пустая память —
   "". Счётчик по умолчанию — `⌈скаляров Unicode / 2,7⌉`.
8. **Ресурс (`Resources/memory.json`).** Шапка блока, подписи строк и отношений, слоты по порядку с подписями, возраст
   словами 1–20, потолки строк, бюджет 300, знаков на токен 2,7, строки состояний. Длинная кириллица — только здесь.
9. **Гейт данных ребёнка.** `scripts/lint/check_child_data.py`: `.sqlite-wal`, `.sqlite-shm`, `.sqlite-journal`, `.db-wal`,
   `.db-shm`, `.db-journal` — в `DATA_EXT`; `magic_kind`: `377f0682`/`377f0683` → «SQLite WAL», `d9d505f920a163d7` →
   «журнал SQLite»; докстринг. `.gitignore`: `*.sqlite-*`, `*.db-*`. Смоук S7 `delivery/evals/smoke/child_data_sqlite.sh`
   — случаи M25 и отрицательный контроль «гейт main `8f938a6` — выход 0» (как S6 у чёрного ящика); строки в README и
   `run.sh`. Доктор после правки — DEAD 0, канарейка гейта прежняя.
10. **CI.** `quality.yml`, джоба `swift`: `LINT_SWIFT_PACKAGES` += `Packages/AllyMemory`; `.swiftlint.yml`: `excluded` +=
    `Packages/AllyMemory/.build`. Джобы, шаги и пороги не меняются; `libsqlite3-dev` уже на образе раннера.
11. **Знание.** Концепт `engineering/memory.md` (Design): обещание, что хранится, опора и уверенность, замена по дате,
    блок, «стереть всё», серия и что ещё не подключено (L50); `implementation:` — исходники пакета (`okf_sync_gate`).
    `KNOWLEDGE.md` §9 — выжимка переезжает в концепт, в §9 остаётся ссылка (OKF §6). `ops/child-data.md` — гейт видит
    спутники базы (его `implementation:` уже держит гейт и `.gitignore`). `engineering/index.md`, карта репозитория,
    `knowledge/log.md`.

## Approach — следующие поставки (уточняют их планы)

- **`memory-extract`.** Зависимость пакета — `AllyDiscipline` (адрес и телефон маршрутизатора — одно определение с
  флагом `forget` сессии). `Forbidden.swift` — правила «не хранится никогда» из ресурса (группы справки: адрес, телефон,
  учреждение, фамилия, чужой взрослый, здоровье, семейное, случай с чужим, пароль) плюс `forget` маршрутизатора;
  функция `forbidden(text)` регистрируется при открытии базы, триггеры `BEFORE INSERT` и `BEFORE UPDATE OF value` у
  `fact` отвергают запрещённое на любом пути (отказ закрытый: функции нет — запись не проходит). Запрос — ресурсы
  `extract.system.ru.md`, `extract.user.ru.md`, `extract.example.json`, `extract.retry.ru.md`, грамматика
  `extract.gbnf` (компактный JSON без отступов — замер справки: S1 189 токенов вместо 377); разбор с одним повтором;
  проверка: номер хода — её реплика, опора (`said` / `found` / `agreed` / без опоры), запрет и «заражение», чужой питомец
  и вымысел (окно 3 реплики после «понарошку», «сон», «сказка», «загадка», «в слова»), отрицание, маркеры любимого.
  Прогон: справочный стенд на Mac (`llama-server` b10809 с тем же весом и той же грамматикой) пишет сырые ответы с хэшем
  запроса в ключе; Swift-проверка судит их тестом-реплеем по выборке в фикстурах и по свежему набору из `local/` (путь —
  аргументом запуска, без набора тест пропускается видимо). Свежий набор пишет другой агент по заказу ведущего.
- **`memory-app`.** Ядро: `MemorySink: TraceSink` в цепочке `TraceFanOut` рядом с `TraceFile` и чёрным ящиком — копит
  её реплики `pass` без `forget` с ответами Элли (`TurnWords`) до записи с `end`, затем кладёт расшифровку в очередь
  (таблица ожидающих в той же базе: id сессии, начало, `audience`, строки; статусы «ждёт / разобрана / не разобрана»,
  попытки, хэши, токены, время). `MemoryKeeper` — разбор по очереди от старых к новым, отмена — сессия ждёт.
  `AllyLlama`: разбор в отдельной последовательности (персона в последовательности 0 остаётся) с грамматикой и своими
  параметрами реестра; пересборка последовательности 0 и файла состояния для «персона + блок». App: каталог
  `Library/Application Support/Memory` (пометка «не в бэкап» с чтением обратно, `NSFileProtectionComplete`, флаг класса
  защиты у SQLite), файл префикса — там же; запуск разбора после записи с `end` и после старта, отмена на `wake`; консоль
  — строка памяти, «Что помнит Элли», «Стереть память» с подтверждением. Реестр `model.json` — раздел разбора (П10);
  снимок поверхности и дифференциальный прогон (M40) — блок «Изменение поверхности модели». Места границы — L7, L16.
- **`memory-forget`.** Удаление факта или сущности с надгробиями (HMAC ключом из Keychain `ThisDeviceOnly`), `secure_delete`
  и сброс WAL с проверкой по байтам; счётчики брата и имени по окну сессии — подсказка на ход и срез третьего упоминания.

- Сеть: ни одного сетевого API (`no_network`); SQLite системный, исходников SQLite и внешних пакетов нет.

- **`memory-forget` ≈ 300:** удаление с надгробиями и проверкой по байтам 90, счётчики окна 60, консоль 30, тесты 120.

## Rejected alternatives

- **Одна поставка на всю память** — отклонено: ≈ 1 960 строк при пределе 800, два рисковых пути и вызов модели, который
  судится только на телефоне.
- **Три поставки (ядро с запретом и блоком, приложение, «забыть»)** — отклонено: `memory-core` с запретом и триггером —
  ≈ 770 > 700 (правило переноса), ожидание ≈ 960 (L52, L61); `memory-app` с проверкой разбора — ≈ 1 050.
- **Фиксированный профиль (вариант A справки) вместо фактов с опорой** — отклонено замером: детали 0,13 против 0,75,
  ловушек 6 против 0 у B2, поправка «Мурка — кошка» 0 из 3 против 3 из 3.
- **GRDB или SQLite.swift** — отклонено: внешний пакет ради десятка вызовов C API (`new_dependency`, сеть при сборке, своя
  лицензия и темп релизов); **свой исходник SQLite (amalgamation)** — отклонено: ≈ 9 МБ кода в git и второй SQLite рядом
  с системным на телефоне.
- **Хранилище файлом JSON вместо SQLite** — отклонено: нет транзакции на сессию (закрытое без предупреждения приложение
  оставит половину, П20), нет триггера запрета на любом пути записи и `secure_delete` для «забыть один» (M41).
- **Запрет значений и триггер в `memory-core`** — отклонено правилом переноса (≈ 770 > 700); триггер без проверки,
  которая его зовёт, судился бы только фикстурами.
- **Уверенность от модели** (поле в JSON) — отклонено: модель не знает, где её реплика (справка: номер реплики верен в
  261 из 270, остальные нашёл код); уверенность — функция опоры, её считает код.
- **Возраст и имена числом и как есть в блоке** — отклонено: персона говорит числа словами, а «ё» и регистр меняли бы
  байты блока от сессии к сессии (П13); написание — самой ранней сессии.
- **Блок с событиями «недавно» и договорённостями сейчас** — отклонено до данных (вопрос 2): нужны даты, сроки и
  признак «сделано» без единого её разговора.
- **Стирание удалением строк вместо удаления файлов** — отклонено: удалённое остаётся в свободных страницах и в WAL до
  чекпойнта; новый файл не несёт ничего из старого, а ключ файла на телефоне уничтожается вместе с ним (Data Protection).
- **Удаление всей истории однозначного признака при замене** — отклонено: родитель видит «было: собака» (справка,
  экран родителя); потолок истории — по данным.
- **Свой модуль SQLite в каждом пакете** — отклонено заранее: два системных модуля под одним именем ломают граф пакетов
  приложения — с серией энциклопедии решает ведущий (Risks спеки).

## Risks

- Бюджет — выше; порог 780 и варианты названы.
- Образ CI без `libsqlite3-dev` — громкий отказ сборки, не тихий пропуск; лечится шагом установки.
- Расхождение SQLite 3.45.1 (Linux) и 3.54.0 (Mac, iOS): используются только `CHECK`, триггеры, WAL, `secure_delete`,
  своя функция — есть с 3.7–3.8; версия печатается в выводе теста.
- Оценка токенов на Linux — 2,7 знака на токен, с запасом к замеру справки (2,71–2,80), но не по построению — порог по
  токенизатору судит `memory-app` (M36).
- Без вызывающего до `memory-app` (L50) — знание и консоль не обещают памяти раньше времени.
- Параллельные правки `quality.yml` (строка `LINT_SWIFT_PACKAGES` у «оболочки»), `.swiftlint.yml`, `CLAUDE.md`,
  `INDEX.md`, `knowledge/log.md` — сложением; перед ссылкой на CI — `mergeable` (L35).
- detect-secrets на ресурсе (L38): в `memory.json` хэшей нет; хэши запроса `memory-extract` — с префиксом `sha256:`.

## Rollout

Установки нет: пакет без приложения. Мерж — ведущий через `merge_guard.sh`. `memory-extract` — после мержа
`memory-core`; `memory-app` — после `memory-extract` (и после R для детских сессий `supervised`, вопрос 3);
`memory-forget` — после `memory-app`.

## Test / eval strategy

- Метки `// M<n>`: `MemoryStoreTests` — M15–M22, `MemoryBlockTests` — M23, M24; M25 — смоук S7 (`# M25`).
  `eval-smoke.md` — после подписи, до кода.
- Базы — во временном каталоге теста, удаляются в `tearDown`; поиск байтов — по всем файлам каталога (`memory.sqlite`,
  `-wal`, `-shm`) в формах UTF-8 имени с заглавной и строчной, с «ё» и «е».
- Мутации в ту же сессию (П30): уверенность не по виду опоры (всегда 0,9) — M19; замена без сравнения дат — M17;
  старое значение удаляется, а не уходит в историю — M16; стирание без удаления `-wal` — M21; эпоха стирания не
  сверяется — M21; ядро вырезается — M23; порядок по id вставки, а не по первому появлению — M24; гейт без правила WAL —
  M25 (смоук красный, старый гейт — выход 0).
- Реляционные оракулы: на 200 случайных лентах сессий с закреплённым зерном — блок ≤ бюджета на каждом шаге, ядро на
  месте, байты блока не зависят от порядка записи сессий без однозначных противоречий; запись той же сессии дважды —
  то же состояние. Детектор канона знает только hypothesis и fast-check — предупреждение разбирается в verify-report, как
  у D1.1, D2 и D3.
- Покрытие AllyMemory ≥ 70% по своему `Sources/` (L41); новые тест-файлы — в сводке утверждений Swift (L26).
